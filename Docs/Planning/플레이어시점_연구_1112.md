## 3. 공통으로 보이는 것

1. **내 편 뒤에 카메라** (1·2·3·4·6·13): 아군 등이 앞, 적이 안쪽. "내가 파티에 있다".
2. **사람 눈높이에 가깝게** (1·3·7): 높이 2~4m. 우리는 7.5m.
3. **행동마다 카메라가 움직임** (1·3·5·9·12): 고를 땐 넓게, 맞을 땐 가깝게. 고정 시점 게임도 순간 확대는 함.
4. **판 보기와 몰입을 섞음** (9·10): 고를 땐 위에서, 결과는 가까이.
5. **차례인 캐릭터가 화면 앞** (2·3·4): 누구 차례인지 카메라로도 알림.

## 4. 우리 게임 제안 (3단계, 위로 갈수록 쉬움)

| 단계 | 내용 | 품 | 위험 |
|---|---|---|---|
| **A. 기본 시점 낮추기** | 카메라를 아군 뒤로 (예: 높이 7.5→4m, 아군 뒤 6~7m). 아군 등이 앞, 적이 안쪽. 화각 36→45° | 반나절 | HUD(이름판·방패·숫자) 위치 다시 확인 |
| **B. 차례 카메라** | 차례인 아군 쪽으로 0.5초 동안 살짝 다가가고 돌아봄. 적 차례면 적 쪽 | 1일 | 많이 움직이면 어지러움 → 작게 |
| **C. 행동 카메라** | 공격·스킬 때 어깨 너머 → 맞는 적 클로즈업 → 원래 자리 (엑스컴식, 1~1.5초) | 1.5일 | 전투가 길어짐 → "연출 끄기" 설정 필요 |
