# 속도 — 행동 순서 확정안 (2026-10-26 기획)

## 원문 (기획 전달)

판타지아 전투는 현재의 라운드당 기본 행동 1회 방식을 유지하겠습니다.

행동 횟수: 아군·적 모두 라운드당 기본 행동 1회입니다. 속도가 높아도 추가 행동은 발생하지 않습니다.
행동 순서: 매 라운드 시작 시 최종 속도 내림차순으로 정렬합니다.
속도 버프·디버프: 다음 라운드의 순서 정렬부터 반영합니다. 이미 정해진 현재 라운드 순서는 바꾸지 않습니다.
순서 조정 효과: 기존 밀기 효과를 유지합니다. 속도 감소와 순서 밀기는 서로 다른 효과로 처리합니다.
타임라인: 현재 라운드와 다음 라운드 예상 순서를 표시합니다. 다음 라운드는 상태 변화에 따라 달라질 수 있으므로 ‘예상’임을 구분해 주세요.
보스·버프 수치: 이번 결정으로는 변경하지 않습니다. 아벨 모로 속도 58보다 명탐정 속도 70이 먼저 행동하는 것은 정상입니다.
기습 실패: 첫 라운드에 적 전원이 먼저 행동하고, 이후 라운드부터 정상 속도순으로 진행합니다. 별도의 추가 공격은 부여하지 않습니다.
그 외: 회피 공식, 도망·몰래 지나가기 판정, 주사위 1~6칸 이동은 현재 규칙을 유지합니다.

기획서에도 “속도는 행동 순서를 결정하며, 기본 행동 횟수를 증가시키지 않는다”를 명시하겠습니다.

## 구현 대조 (개발)

| 항목 | 상태 | 위치 |
|---|---|---|
| 라운드당 행동 1회, 추가 행동 없음 | 기존 구현과 같음 | Combat/BattleQueue |
| 라운드 시작 시 최종 속도 내림차순 (동률: 아군 → 편성 순) | 기존 구현과 같음 | BattleQueue.ComputeOrder |
| 속도 버프·디버프는 다음 라운드부터 | 기존 구현과 같음 (라운드 중 재정렬 없음) | BattleQueue.StartNextRound |
| 밀기(방해함·초기화)는 속도 감소와 별개 | 기존 구현과 같음 | BattleQueue.Shift |
| 타임라인: 현재 + 다음 라운드 예상 | **수정** — 다음 라운드까지만 표시(전에는 R3까지), 다음 라운드 칸은 흐리게 + "R2 예상" 표시 | BattleQueue.Preview, UI/BattleHud.SetTimeline |

| 회피·도망·몰래 지나가기·주사위 이동 | 변경 없음 | — |

# 전투 행동 순서 개선 확정안 (2026-10-26 기획 — 개발 추천 A+D)

## 원문 (기획 전달)

[기획 → 개발] 전투 행동 순서 개선 확정안

개발 추천인 A+D로 진행해주세요. 적용 규칙은 다음과 같습니다.

기본 전투 규칙 유지
라운드당 각 캐릭터 1회 행동.
라운드 시작 시 속도순으로 행동 순서 확정.
전투 중 속도 변화는 다음 라운드 정렬부터 반영.
B의 저지 사격 변경과 C의 기본 속도 조정은 보류합니다.

신속의 앰플 추가
1막 상점에서 판매.
자신을 포함한 아군 1명에게 사용.
사용 시 행동 1회 소모.
효과: 속도 +15.
사용 즉시 효과를 부여하고, 다음 라운드부터 순서에 반영.
사용한 라운드는 지속 시간에서 제외하며, 이후 2개 라운드 종료까지 유지.
같은 앰플은 중첩되지 않고 지속 시간만 갱신.
추가 속도 조절 스킬은 앰플 적용 후 체감을 확인하고 검토합니다.

   예시:
   
역병 의사 53 → 68: 아벨 모로 58보다 먼저 행동.
저격수 33 → 48: 아벨 모로보다 뒤에 행동.

   따라서 아이템 설명에도 '속도 +15'를 표시하고, 선행 행동을 보장하는 표현은 사용하지 않습니다.

타임라인 표시 보강
초상화 아래에 이번 라운드 정렬에 사용한 속도 표시.
전투 중 속도가 변하면 상태 아이콘과 함께 '다음 라운드 순서에 반영' 안내.
다음 라운드 시작 시 순서가 앞당겨지면 ↑, 늦춰지면 ↓를 잠깐 표시.
사망자를 제외한 생존자끼리 순서를 비교하여, 사망으로 빈자리가 당겨진 경우에는 화살표를 표시하지 않습니다.

속도 감소 중첩 오류 수정
현재 유효한 감소 효과 중 감소량이 가장 큰 하나만 적용.
−25 상태에서 −15가 추가되어도 −25 유지.
각 효과의 지속 시간은 별도로 관리.
−25가 끝났을 때 −15가 남아 있으면 −15 적용.
동일 효과 재적용은 기존 지속 시간 갱신 규칙을 따릅니다.

완료 확인
사용한 라운드의 행동 순서가 유지되는지.
다음 라운드에 속도 변화가 반영되는지.
효과 만료 후 순서가 정상적으로 다시 계산되는지.
강한 감소 효과가 약한 효과로 덮어써지지 않는지.
앰플을 사용한 보스전에서 선행 회복과 상태이상 대응이 과도하게 유리해지지 않는지 확인해주세요.

목표는 플레이어가 필요한 순간 행동 순서를 조절하고, 그 결과를 화면에서 확인하게 하는 것입니다.

## 개발 반영

| 항목 | 게임에서 보이는 것 |
|---|---|
| 신속의 앰플 | 런던 상점 보급품에 추가 (65 Cent). 전투 중 소모품 → 아군 1명 클릭. 설명: "아군 1명 속도 +15 …" (먼저 행동한다는 표현 없음) |
| 기간 | 사용한 라운드는 순서 그대로 → 다음 2라운드 동안 반영 → 그다음 라운드에 원래 속도로 다시 정렬. 상태 칸에 "속↑2" → "속↑1" |
| 다시 쓰면 | 속도는 +15 그대로, 기간만 처음부터 |
| 속도 숫자 | 타임라인 초상 아래 "속도 73" — 이번 라운드 칸은 정렬에 쓴 값, 흐린 다음 라운드 칸은 지금 속도(예상) |
| 속도 변화 안내 | 화면 가운데 "역병 의사 속도 53 → 68 · 다음 라운드 순서에 반영" (앰플·속박·저지 사격·중독 모두) |
| ↑ / ↓ | 새 라운드가 시작되면 앞당겨진 캐릭터에 초록 ↑, 늦춰진 캐릭터에 빨강 ↓ (2.5초). 쓰러진 캐릭터 때문에 당겨진 건 표시 안 함 |
| 속도 감소 겹침 | 가장 큰 감소 하나만 적용, 효과마다 기간 따로 |

해석한 부분 → 아래 "기획 확인·확정"에서 확정됨:
- 런던 상점 수량 2개 (원문에 수량 없음 — 개발 임시값)
- ↑/↓는 순수 속도 순서끼리 비교. 기습으로 바뀐 첫 라운드 순서, 방해함·초기화로 밀린 자리는 비교에서 뺌 (속도 때문에 바뀐 것만 표시)
- 앰플은 전투 중에만 사용 가능 (보드에서는 쓸 수 없음)

## 기획 확인·확정 (2026-10-26)

원문:

[기획 → 개발] 확인 및 확정 사항

런던 상점 앰플 수량
전달문에 수량이 빠져 있어, 초기 재고 3개로 정하겠습니다.

↑/↓ 비교 기준
속도 변화 때문에 행동 순서가 바뀐 경우에만 표시해주세요.
기습 첫 라운드의 특수 순서, 행동 방해, 사망·이탈에 따른 변동은 제외합니다.
속도 효과가 만료되어 순서가 돌아오는 경우도 표시 대상입니다.

앰플 사용 장소
전투 중에만 사용 가능으로 확정합니다.
보드에서는 사용 불가로 처리해주세요.
기존에 정한 행동 1회 소모와 지속 시간 규칙을 적용합니다.

추가 속도 조절 스킬
현재는 추가를 보류합니다.
실제 플레이 후 앰플의 사용 빈도, 순서 조절의 유용성, 보스전 난이도 영향을 확인하고 결정하겠습니다.

개발 반영:
| 항목 | 상태 |
|---|---|
| 런던 앰플 재고 3개 | 반영 (2 → 3) |
| ↑/↓ 기준 | 이미 같은 방식 — 속도 순서끼리 비교, 기습·방해·사망·전투 이탈 제외, 효과 만료로 돌아오는 것도 표시 (셀프 테스트로 확인) |
| 전투 중에만 사용 | 이미 같음 — 보드 인벤토리에서는 사용 불가 |
| 추가 속도 스킬 | 보류 (작업 없음) |
