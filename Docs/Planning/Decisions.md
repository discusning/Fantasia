## 2026-10-24 — 보드 1인 이동

**기획 결정**
| 항목 | 결정 | 원문 대비 |
|---|---|---|
| 월드 턴 | **[아군 턴] → [적 턴]** 2단계. 둘을 마치면 1월드 라운드 | "생존 아군 전원이 각자 월드 행동을 마친 주기" 대체 |
| 보드 이동 | 파티장 1명이 파티 전체를 이끌고 이동 | 캐릭터별 개별 이동 대체 |
| 파티장 | **1번 캐릭터 고정**, 변경 시스템 없음 | 신규 |
| 월드 UI | 세부 월드 타임라인 제거, 상단에 **[아군 턴 / 적 턴] 표시**만 (UI 시안 대기) — 임시안: `UI/BoardTopBar` (조사: `../References/BoardTurnUI_Research_2026-10-24.md`) | 보드 타임라인 삭제 (전투 타임라인은 유지) |
| 도시 서비스 | 숙박·치료·명상·수리 등 **3명 일괄 적용** | "해당 캐릭터 1명" 대체 |
| 성급함의 기도 | **삭제** (대체 없음) — 석상 기도 7종 | 기도 8종 → 7종 |

**결정에 따라 정리된 규칙**
- 조우 참가 범위(시작 타일 2칸) 삭제 — 항상 3명 전원 참가.
- 이벤트 칸 추가 이동: 개인 월드 턴당 1회 → **아군 턴당 1회**.
- 속도는 월드 이동 순서에 쓰이지 않음 (전투 순서·회피·몰래 지나가기 판정용).
- 텔레포트권·장비 교체의 "현재 캐릭터" → 파티.

**개발 임시 결정** (월드 보드가 아직 구상 전 — 보드 설계 때 다시 확인)
| 항목 | 임시 결정 | 코드 |
|---|---|---|
| 적 턴에 하는 일 | 월드 라운드 처리만 (피의 흔적 G·영혼 수확 S·사신 추격·상점 재고). 일반 적은 고정 — 사신 예외는 아래 2026-10-24 결정 | `World/WorldTurnRules.RunEnemyTurn` |
| 아군 턴 끝나는 시점 | 이동(+ 이벤트 추가 이동)과 도착 칸 처리가 끝나면 자동 종료. 전투로 끝난 턴은 보드 복귀 후 적 턴 | `Board/BoardTestController.EndAllyTurn` |
| 기습·몰래 지나가기 판정자 | 파티장 | `UI/EncounterPanel` |
| 도시 서비스 비용 | 1인 가격 × 3명, 이용하면 아군 턴 종료 | D20에서 구현 |
| 중독의 보드 피해 | **아군 턴 시작 시 1회** (HP 1 하한) | `World/WorldTurnRules.BeginAllyTurn` |
