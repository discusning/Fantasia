**결정에 따라 정리된 규칙**
- 조우 참가 범위(시작 타일 2칸) 삭제 — 항상 3명 전원 참가.
- 이벤트 칸 추가 이동: 개인 월드 턴당 1회 → **아군 턴당 1회**.
- 속도는 월드 이동 순서에 쓰이지 않음 (전투 순서·회피·몰래 지나가기 판정용).
- 텔레포트권·장비 교체의 "현재 캐릭터" → 파티.

| 항목 | 결정 | 이전 임시값 |
|---|---|---|
| 이름 | 게이지 100 도달 이벤트 = **피의 사냥** | — |
| 시작 | 인조 그림자 사신은 처음에 필드에 없음. 적 턴마다(적이 실제로 공격하지 않으므로) 피의 흔적 게이지가 참 | 같음 |

| 실패 | 3아군 턴 안에 1마리도 못 잡으면 → **3명 중 무작위 1명 HP·MP 모두 1**, 게이지 0, 피의 사냥 종료 | HP 1 + 영혼 수확 +5 |
