기본 행동과 상태 효과
• 해부의 일격 → 해부의 일격 → 봉인된 수은을 반복합니다. 해부의 일격은 물리 1.0A·단일 대상이며, 크리티컬 명중
시 약한 출혈 3턴을 적용합니다. 단일 공격 대상은 생존 아군 중 현재 HP 비율이 가장 낮은 1명, 동률은 편성 순서로 정
합니다.
• 봉인된 수은은 마법 0.8M·아군 전체 공격입니다. 이번 변경으로 명중한 대상에게 중독 1스택을 확정 적용합니다. 크
리티컬에도 중독은 총 1스택이며, 회피한 대상은 피해·중독을 모두 받지 않습니다. 이 기술만 공통 “크리티컬 시 상태 적
용”의 예외입니다.
• 중독은 기존 규칙인 최대 3스택·개인 턴 시작마다 스택×3 피해·HP 1 하한·스탯 -5 1회만 적용합니다. 전투 종료만으
로 자동 해제하지 않습니다. 회복·해독을 배우는 첫 보스로 사용합니다.
HP 60% 이하에서 금지된 봉합 1회
• HP가 180 이하가 되면 사용을 예약합니다. 다음 보스 개인 턴은 공격 대신 봉합을 예고하고, 그 다음 보스 개인 턴에
HP 60을 회복합니다. 예고·회복 행동은 공격 피해가 없습니다. 0 HP로 쓰러진 보스에게 예약을 실행하지 않습니다.
• 예고부터 실행 전까지 최소 1명의 아군에게 명령을 선택할 개인 턴을 보장합니다. 기회가 없었다면 회복 실행을 다음
보스 턴으로 미룹니다. 봉합이 끝나거나 취소된 뒤에는 저장한 기본 패턴 순서로 복귀하며, 패턴을 처음부터 리셋하지
않습니다.

• 저지 성공 시 UI를 봉합 저지 성공으로 1.5초 바꾸고 예고를 제거합니다. 보스의 예정된 회복 행동은 “봉합 실패”로

제한을 지킵니다.
• 1.3A인 명탐정 일점 돌파와 1.2A인 저격수 관통탄은 공격 저지가 가능합니다. 0.9A인 저지 사격은 이름과 관계없이
봉합 취소 조건을 만족하지 않습니다. 크리티컬 배율을 기술 계수에 더해 판정하지 않습니다.
• 스킬의 집중력 비용과 슬롯 1개 확정용 추가 집중력은 별도입니다. 집중력 부족 시에도 「봉합 방해」는 활성 상태를 유
지합니다. 이미 취소됐거나 보스가 쓰러졌다면 중복 실행·추가 행동 소모를 막습니다.
3막과의 구분: 인공 사신의 수확 취소는 기존 “집중력을 사용한 크리티컬 명중” 조건을 유지합니다. 무료 「봉합 방해」
를 다른 보스의 만능 저지 버튼으로 적용하지 않습니다.

첫 턴 시작. 배너에는 “1막 보스 / 검시관 아벨 모로”를 표시합니다. 보스 BGM은 필드 음악이 꺼진 뒤 한 번만 시작해 전
투 중 반복합니다.
재도전: 같은 플레이에서 이미 본 경우 배너 1초 후 전투로 들어갑니다. 대화는 자동 생략합니다. 최초 대화도 클릭
/Space로 다음 줄을 볼 수 있고 [연출 건너뛰기]로 끝낼 수 있습니다. 건너뛰기는 화면 재생만 생략하며 초기화·턴·보상
처리에 중복 진입하지 않습니다.
최종 전용 음악을 받기 전에는 보유한 보스용 임시 트랙을 연결합니다. 논리 음악 ID는 BGM_Boss_Abel로 제안하며 기존 ID 체계에 매핑
합니다. 음악 없음·중복 재생·일반 전투 음악이 계속 남는 상태로 완료 처리하지 않습니다.
전투 전 - 4줄
  명탐정 검시 기록을 고친 건 당신이군. 제임스 부인의 시신은 어디로 보냈지?
  아벨 모로 시신만 보는 눈으로는 이해할 수 없지. 그분들이 원한 건 껍데기가 아니야.
  명탐정 이 문양… 현장의 상처와 같은 룬이다. 여기서 끝내겠다.
  아벨 모로 그렇다면 너희도 다음 장부에 올려 주마.
보스 처치 후 - 4줄
  아벨 모로 장부를 가져가도… 운반은 이미 시작됐어.
  명탐정 피해자 명단… 제임스의 부인도 있어. 베르사유 귀족의 인장이군.
  역병 의사 이 룬 조각은 영혼을 가두는 용기와 연결돼 있어요.
  명탐정 검시소는 시작에 불과했어. 제임스에게 알리고, 운반 기록을 추적하자.
제임스에게 보고 - 2줄
  제임스 아내에게… 대체 무슨 일이 있었던 겁니까?
  명탐정 검시소의 범행은 멈췄습니다. 하지만 지시한 자는 따로 있습니다. 남은 기록을 따라 끝까지 추적하겠습니다.
처치 후 진행 순서
HP 0 확정 → 전투 입력과 예고 종료 → 처치·최초 보상·증거품·퀘스트 갱신을 중복 없이 함께 저장 → 처치 후 대화 →
보상 창 → 월드 복귀 순서입니다. 처치 직후 보스 BGM을 0.7초에 걸쳐 종료합니다. 월드 복귀 시 해당 지역 BGM을 재
생합니다.
보스 처치와 증거 확보 후 목표는 “제임스에게 보고”로 바뀝니다. 보고 대화 완료 시 1막을 완료하고 “베르사유의 운반 기록 추적”을 활성화
하며 다음 지역을 해금합니다. 자동 지역 이동은 하지 않습니다. 대사 생략·재접속도 동일한 진행 결과를 보장합니다.
