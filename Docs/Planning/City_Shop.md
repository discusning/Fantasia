# 공통 보급과 지역 보급

가격은 1개 기준 Cent. 수량은 재입고 후 최대 재고다.

모든 표는 완성 범위의 추가 설계안이다. 기존 가격·효과·소모품 최대 재고는 유지하고, 도시별 취급 여부와 장비 수량을 새로 배정했다. 숫자 0은 해당 도시에서 판매하지 않는다는 뜻이다.

# 거래 처리와 구현 확인

표의 숫자를 실제 재고로 적용하기 위한 최소 규칙이다.

## 13. 거래와 품절 처리

- 상품은 고정 목록이다. 같은 재입고 때 품목이나 등급을 다시 추첨하지 않는다. 재입고는 수량만 회복한다.
- 구매 시 가격·남은 재고·판매 조건·인벤토리 여유를 함께 확인한다. 실패하면 Cent와 재고 모두 변하지 않는다. 소모품은 종류당 10개, 시약은 30개, 일반 장비는 20개 보관 한도를 적용한다.
- 되팔기는 정상 구매가의 40%를 소수점 버림으로 지급한다. 파손 장비는 그 정상 되팔기 가격의 10%를 적용한다. 최초 지급 무기는 0, 고유 장비·퀘스트 아이템은 판매 불가다.
- 판매한 물건은 고정 판매 재고에 더하지 않고 이번 설계에서는 재판매 진열도 하지 않는다. 한정품을 되팔아도 1회 구매 기록은 유지한다.
- 품절 상품은 목록에 남기고 수량 0과 다음 재입고까지 남은 월드 라운드를 표시한다. 한정품은 구매 완료로 표시하고 재입고 안내를 띄우지 않는다.
- 미해금 품목은 해금 조건을 표시하고 구매를 막는다. 구현하지 않은 확장 도시와 직업 전용 상품은 현재 빌드에서 숨긴다.

## 15. 확인할 동작

- 라운드 0에 생명의 영약 2개 구매 → 남은 1개 → 완료 라운드 3에 정확히 3개.
- 상점을 닫고 다시 열기, 다른 캐릭터로 구매, 저장 후 불러오기로 수량이 늘지 않는지 확인.
- 런던에서 산 품목이 베르사유 재고에 영향을 주지 않는지, 장기간 미방문 후 재입고가 최대 수량을 넘지 않는지 확인.
- 월계관·집문서 구매 뒤 라운드 3·6·9, 도시 왕복, 저장 후 불러오기에도 다시 판매되지 않는지 확인.
- 소지금 부족·인벤토리 가득 참·미해금·품절 상태에서 Cent나 재고가 차감되지 않는지 확인.

## 16. 초반 구매 예시와 근거

시작 자금 180 Cent 기준: 생명의 영약 1개(50) + 마력의 영약 1개(30) + 집중의 향초 1개(45) + 해독제 1개(25) + 압박 붕대 1개(20) = 170 Cent, 잔액 10 Cent. 시작 무기는 이미 지급되므로 첫 구매가 무기 교체에 묶이지 않는다.
