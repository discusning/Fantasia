A1 · 피의 사냥

예전사신 4마리 · 1마리만 잡으면 끝 · 아군 턴마다 2칸 · 아군 턴 3번 제한
지금사신 3마리 · 전부 잡아야 끝 · 라운드마다 1칸 · 3월드 라운드 제한
  • 피의 흔적이 100이 되면 파티 근처 1~2칸에 사신 3마리가 나타남 (빈 칸이 모자라면 조금 더 먼 칸)
  • 나타난 바로 그 아군 턴에는 사신이 움직이지 않음 → 도망·준비할 시간
  • 사신 1마리 잡을 때마다: 35 Cent + 경험치 40 (전투 보상)
  • 3마리 전부 잡으면: 100 Cent + 생명의 영약 1개, 피의 흔적 0
  • 3라운드 안에 못 잡으면: 살아 있는 1명이 HP 1 (MP·LP는 그대로), 영혼 수확 +5, 남은 사신 사라짐
  • 끝난 뒤 2라운드 동안은 피의 흔적이 오르지 않음 (유예)
  • 안내 칸에 "남은 라운드 · 남은 사신" 이 계속 보임
사신 3마리 출현 직후 — 왼쪽 위 안내 "3라운드 안에 전부 처치 / 남은 라운드 3 · 남은 사신 3", 위 바에 "피의 사냥 진행 중"

A3 · 저장 실패

예전저장 실패 창이 떠서 게임이 멈춤 → [다시 시도]를 눌러야 진행
지금게임은 멈추지 않음. 알림만 뜨고, 다음 자동 저장 때 다시 시도
  • 알림 문구: "저장에 실패했습니다. 게임은 계속 진행되며 다음 자동저장 때 다시 시도합니다." (4초)
  • 저장이 다시 성공할 때까지 왼쪽 위 안내 칸에 빨간 "저장 실패" 줄이 계속 남음
  • 실패가 이어져도 알림은 처음 1번만 (같은 알림이 계속 뜨지 않게)
  • 메인 메뉴로 나가기 · 게임 종료 전에 실패 중이면 한 번 더 저장 시도 (막지는 않음)
  • 저장은 임시 파일에 먼저 쓰기 때문에, 실패해도 마지막으로 성공한 저장 파일은 그대로 남음 → 메인 메뉴의 저장 시각도 성공한 것만 보임
일부러 저장을 막아 본 화면 — 위쪽 알림 + 왼쪽 위 빨간 "저장 실패" 줄. 막은 것을 풀자 다음 저장 성공, 빨간 줄도 사라짐

B1 · 상점의 잠김 무기

1막에서는 살 수 없는 2막 무기 3개(은도금 해부단검 · 은탄 수사권총 · 연금술 룬 스태프)를 목록에서 뺐습니다. 데이터는 지워지지 않아서 2막이 열리면 다시 보입니다.

예전 — "잠김" 무기 3개가 같이 보임
지금 — 살 수 있는 3개만

B3·B4·B7 · 턴 판 (아군 턴 / 적 턴)

  • 월드에서 아군 턴 ↔ 적 턴이 바뀔 때만 나옴 (전투 안의 개인 턴에는 안 나옴)
  • 위 바에 매달린 판이 떨어져 멈추기까지 약 1초, 잠깐 머문 뒤 흐려지며 사라짐
  • 판이 내려오는 동안은 주사위(Space)·칸 클릭을 받지 않음 → 턴이 두 번 시작되지 않게
  • 적 턴은 짧아서(0.9초) 바로 아군 턴이 옴 → 판을 다시 떨어뜨리지 않고 글자만 바꿈 (보고서 "제목만 바꿈")
  • 소리: 받은 사슬·멈춤 소리 2개를 한 번씩. 설정의 효과음 볼륨을 따름
  • 예전에 따로 만든 "턴 전환 효과음" 자리 2개는 판 소리와 겹쳐서 뺌 (효과음 표 20 → 18종)
아군 턴 — "명탐정이(가) 파티를 이끈다"
적 턴 — "교단이 움직인다..."
