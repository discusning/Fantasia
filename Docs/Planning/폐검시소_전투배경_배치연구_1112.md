## 2. 정리한 규칙 (우리 전투에 맞춤)

1. **싸움 자리 비움**: 아군 x −2.6 ~ 적 x +2.6 사이, 카메라 → 적 시선 위엔 아무것도 없음.
2. **보스 뒤 표지물**: 아벨 모로 뒤 (x +7~8)에 검시대 + 시체. "검시관의 자리".
3. **3겹 깊이**: 앞(가림막, 화면 가장자리) · 가운데(검시대) · 뒤(약품장·기록대·문, 벽 쪽 줄).
4. **빛 웅덩이 하나**: 검시대 위 차가운 등 1개. 나머지는 지금 보스 조명처럼 어둠 (안개로 벽이 없어도 실내처럼).
5. **높이 섞기**: 매달린 해골(높음) · 약품장(중간) · 세척대(낮음).
6. **들어온 문은 아군 뒤쪽 먼 줄**: 파티가 문으로 들어온 느낌.
7. **카메라 쪽엔 낮은 것만**: 화면을 막지 않게.

## 3. 배치안 (위에서 본 그림, 카메라는 왼쪽 아래)

```
 z +11   [약품장]  [약품장]   [검시기록대]      [폐검시소 문]
 z  +8          [세척대]                [매달린 해골]
 z  +3                                  
 z   0   아군 ●●●  (비움)  적 ◆ 아벨     [검시대+시체]  ← 위에 차가운 등 1개
 z  -6                                   [가림막]
         x −2.6           x +2.6        x +7.5
 카메라 (−9, 7.5, −12.5) ↗
```

| 구조물 | 위치 (x, z) | 바라봄 | 이유 |
|---|---|---|---|
| 검시대 + 시체 | (7.5, 0.5) | 카메라 | 보스 뒤 표지물 (규칙 2) |
| 매달린 해골 | (8.5, 7) 높이 3m | 카메라 | 높이 섞기 (규칙 5) |
| 약품장 ×2 | (−6, 11) · (−2, 11) | −z | 뒤 줄 (규칙 3) |
| 검시기록대 | (3, 11) | −z | 검시실 3종 세트 (6번) |
| 세척대 | (−3, 8) | −z | 낮은 중간 줄 |
| 폐검시소 문 | (9, 11) | 모서리 쪽 | 먼 모서리, 안개에 반쯤 (규칙 6) |
| 가림막 | (8, −6) | −x | 오른쪽 앞 액자 (5번) — 적 줄 밖 |

- 조명: 검시대 위 점광원 1개 (푸르스름한 흰빛, 범위 6m). 지금 보스 조명은 그대로.
