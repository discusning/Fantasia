# 런던 이벤트·십자가 석상 구현 확정 (2026-10-26 기획 — 대기 요청 2번·37~40 답)

## 원문 (기획 전달)

[기획 → 개발] 런던 이벤트·십자가 석상 구현 확정

**1. 런던 이벤트 배정**

| 위치 | 확정 이벤트 |
| --- | --- |
| M02 | 점술마녀 |
| S10 | 분수대 |

런던에서는 위 2종을 경험하도록 구성합니다.

**2. 이벤트 배정 방식**

전체 이벤트 칸 6곳 모두 **칸마다 고정 배치**합니다. 재방문하거나 새 게임을 시작해도 해당 칸의 이벤트 종류는 같습니다.

분수대는 **해당 칸당 한 회차에 파티 공유 1회** 사용할 수 있습니다. 재방문·저장 후 불러오기로 사용 횟수가 초기화되지 않습니다.

**3. 십자가 석상 기도 선택**

1차 구현에서는 **모든 석상에서 아래 6종 전체를 선택지로 제공**합니다.

- 집중·부·생명·그림자·피·지혜

순수·성급함은 관련 시스템 구현 이후 추가하며, 1차 선택 창에서는 숨깁니다.

사용 규칙은 다음과 같습니다.

- 석상 하나당 **한 회차에 파티 전체에서 1회** 사용합니다.
- 기도를 받을 캐릭터 1명과 기도 1종을 선택합니다.
- 캐릭터당 활성 기도는 1개입니다. 다른 석상에서 새 기도를 받으면 기존 기도 효과를 제거하고 교체합니다.
- 선택을 확정했을 때 사용 횟수를 소모합니다. 취소하면 소모하지 않습니다.
- 기도 효과와 수치는 기존 시스템 기획서를 적용합니다.
