팀장 요청: 같은 종류만 나오면 3D 모델 1마리. 다른 종류면 2마리 모두. 화면을 나누는 느낌으로. 3D 게임 15개 이상 조사.

## 정리
- 18개 중 13개가 화면을 둘(이상)로 나눔. 그중 8개가 **비스듬한 선**.
- 나눌 때는 대부분 **양쪽 크기가 같음**.
- 칸마다 **얼굴이 가운데**. 이름은 **칸 구석**.
- 나누지 않는 게임(16~18)은 목록·차례 소개 → 우리 "적 구성" 칸이 이미 이 역할.
- 대결 화면 디자인 자료: 비스듬한 세로선이 화면을 둘로 나누기 좋음. 가운데를 비워 두지 말 것.

## 적용
- 다른 종류 2마리: 비스듬한 금색 선(12도)으로 둘. 왼쪽 = 만난 적(대표), 오른쪽 = 다른 종류. 크기 같음.
- 칸마다 어두운 바탕 색 (왼쪽 붉은빛, 오른쪽 남색) → 나뉜 느낌.
- 이름은 칸 위 구석 (왼쪽 칸은 왼쪽, 오른쪽 칸은 오른쪽).
- 판정 칸 수 원(대표 적 기준)은 왼쪽 칸 아래.
- 같은 종류만: 예전처럼 1마리. 3종류 이상: 앞 2종류만 (적 구성 칸에 전부).
