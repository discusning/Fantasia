# 도시 구성과 역할

본편 3개 거점만 한다.

기존 시스템 기획의 아이템 명칭·가격·효과·기본 최대 재고를 유지하고, 비어 있던 도시별 판매 배정과 장비 수량을 보완한 초기 설계안이다. 아직 플레이테스트를 마친 수치는 아니다.

## 1. 본편과 확장 거점

| 도시·범위 | 랜드마크와 역할 | 해금 조건 | 상점의 특징 |
| --- | --- | --- | --- |
| 런던 / 1막 | 그리니치 전망대·수사대 상점. 탐정 사무소와 검시소 수사의 출발점. | 게임 시작 | 기초 보급·기습 도구·수사 장비 |
| 베르사유 / 2막 | 궁전 외곽 시민 상가. 궁정 잠입과 지하 예배당 조사 준비. | 검시관 처치 후 2막 진입 | 마력·집중력·저주 정화·희귀 마법 장비 |
| 로마 / 3막 | 제국 광장·성소 시장(신규 제안). 고성 시험 시설 진입 전 최종 보급. | 붉은 주교 처치 후 고성 진입 단계 | 고급 보급·에픽 장비·마리의 감정소 |

본편 이동 순서는 런던 → 베르사유 → 로마다. 프랑크푸르트와 베네치아는 선택 확장 지역이며, 두 도시를 방문하지 않아도 3막을 끝낼 수 있다.

## 2. 기존 문서 간 지역 설정 정리

- 시스템 문서의 런던·베르사유·프랑크푸르트·베네치아를 유지하고, 스토리의 3막 무대인 로마를 본편 거점으로 추가한다.
- 런던의 랜드마크는 현재 시스템 문서에 적힌 그리니치 전망대를 사용한다. 로마의 제국 광장·성소 시장은 이번 문서에서 제안한 이름이다.
- 도시의 특화는 판매 품목으로 구분한다. 같은 아이템에 지역 가격 배율을 추가하지 않는다.

## 3. 보드판 배치

- 도시는 육각 보드의 안전 타일 1개와 연결 도로로 만든다. 돌길 타일을 기본으로 쓰고, 본편 도시 사이 이동 거리는 기존 50~60칸을 유지한다.
- 주 경로와 원정 경로가 도시 입구에서 갈라지게 배치하고, 도시 타일은 막다른 길로 만들지 않는다. 방문 후 기관차 목적지로 등록한다.
- 도시 안전 타일에서는 적 조우를 발생시키지 않는다. 주변 필드의 위험과 월드 라운드 진행은 계속 적용한다.

# 이용 규칙과 재입고

세계 시간, 공유 재고, 1회 한정품을 같은 기준으로 처리한다.

## 4. 도시 화면과 공통 시설

도시 타일에서 한 화면을 열고 보급품 / 무기 / 방어구·장신구 / 서비스 / 의뢰 탭을 제공한다. 판매 NPC를 여러 명 배치해도 같은 도시의 동일 품목은 재고를 공유한다.

| 시설·서비스 | 가격(Cent) | 효과와 행동 비용 |
| --- | --- | --- |
| 숙박 | 30 / 캐릭터 | 선택 캐릭터 최대 HP·MP 50% 및 집중력 1 회복, 혼란·공포 제거. 해당 월드 행동 종료. |
| 정밀 치료 | 50 / 캐릭터 | 중독·출혈·화상·저주·부식 제거. 죽음의 표식 제외. 해당 월드 행동 종료. |
| 집중 명상 | 45 / 캐릭터 | 선택 캐릭터 집중력 최대치 회복. 해당 월드 행동 종료. |
| 무기 수리 | max(40, 정상 가격의 20%) | 무기 1개 복구. 계산 금액 올림. 해당 월드 행동 종료. |
| 방어구·장신구 수리 | max(30, 정상 가격의 20%) | 해당 장비 1개 복구. 계산 금액 올림. 해당 월드 행동 종료. |
| 작업대·의뢰 | 기존 제작표·보상표 적용 | 제작은 시약·제작비를 내고 1개 확정 제작, 월드 행동 종료. 도시 의뢰는 의뢰별 최초 1회 보상. |

구매·판매는 현재 캐릭터의 이동 종료 전 가능하며 행동을 추가 소모하지 않는다. 파티 지갑은 공유한다. 서비스는 상품 재고를 쓰지 않지만 비용과 행동을 매번 소모한다.

## 5. 3월드 라운드 재입고

- 수량 단위: 표의 숫자는 1캐릭터당 수량이 아니라, 해당 도시에서 파티 전체가 함께 구매할 수 있는 최대 수량이다.
- 시간 기준: 생존 아군 전원이 월드 행동을 한 번 마치면 1월드 라운드가 지난다. 전투의 개인 턴·전투 라운드와 상점 화면 체류 시간은 재입고 시간을 늘리지 않는다.
- 시작 상태를 완료 라운드 0으로 두고, 완료 라운드 3·6·9…마다 모든 해금 도시의 일반 상품을 최대 수량까지 보충한다. 남은 수량에 최대 수량을 더하지 않는다.
- 예: 최대 3개인 영약을 2개 사면 1개가 남고, 다음 재입고에 3개가 된다. 도시를 방문하지 않은 동안에도 세계 시간은 적용하되 놓친 재입고를 누적 적립하지 않는다.
- 방문·상점 다시 열기·도시 왕복·저장 후 불러오기로 재입고하지 않는다. 새 도시나 판매 단계가 처음 해금되면 신규 품목만 최초 1회 최대 수량으로 개시한다.
- 생명의 월계관은 도시당 플레이 전체 1개, 마리의 집문서는 로마의 마리 상점에서 플레이 전체 1개다. 두 상품은 구매 후 재입고하지 않는다.

## 6. 제작 순서

- 1차 구현: 런던, 명탐정·역병 의사·저격수용 노말 무기 3종, 노말 방어구 4종, 공통 보급과 런던 지역 보급, 거래·재입고·한정품 저장.
- 2차 구현: 베르사유와 로마, 희귀·에픽 판매 단계, 나머지 직업 장비, 수리·제작·고성 진입 연동.
- 3차 구현: 프랑크푸르트·베네치아의 선택 경로. 전체 판매표는 완성 범위의 데이터이며, 아직 구현하지 않은 직업·시스템 품목은 1차 빌드에서 숨긴다.
