- 보드: 바닥을 돌길 칸으로 바꿈
- 보드 구조물: 거점 건물, 보스 건물(검시소), 보물 상자, 우물, 점술 천막, 분수, 출구 문

- 화면 보고서 PDF: 팀원공유 폴더 "2026-11-06_에셋적용_인게임_보고서.pdf"

■ 2. 움직임(애니메이션) 적용 가능 여부
- 받은 인물은 뼈대(리깅)가 정상 → 움직임 파일만 오면 바로 재생 가능
- 개발이 만든 임시 자세로 T자 자세는 풀어 둠 (사람형 6개)
- 사냥개·가고일은 사람 몸이 아니라서 받은 Idle이 꼭 필요
- 움직임 요청서 보냄: 11/7(토) Idle 먼저, 나머지 11/11까지

■ 3. 전투 규칙 변경 (팀장 결정)
- 퇴각: 한 명이라도 퇴각에 성공하면 → 파티 전원 같이 빠짐
  (판정은 그대로: 고른 캐릭터 속도로 2칸, 실패하면 차례만 소모)
- 집중: 켬/끔 1개 → 쓸 개수를 직접 고름
  - 행동 메뉴 오른쪽 [−] 집중 사용 2/3 [+]
  - 1개당 판정 칸 1개 확정 성공
  - 판정 칸 수까지만 씀 (스킬 집중 비용은 따로)
- 확인: 자동 테스트 34개 통과, 실패 0

■ 4. 기획 확인 부탁
- 집중으로 칸을 전부 확정하면 크리티컬 확정
- 예: 명탐정 무기(2칸) → 집중 2개면 매번 크리티컬
- 이대로 갈지, 상한(예: 칸 수 −1까지)을 둘지 정해 주세요
