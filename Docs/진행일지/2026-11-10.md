# 2026-11-10 진행일지

기획·디자인 결론(UI 보고서 답 + 상의 결론) 기다리는 동안, 결과와 상관없이 해야 하는 점검.

## 음악 반복 틈 고침
- 원인: 받은 MP3 4곡 모두 Unity가 앞쪽 인코더 지연 약 47ms(2257샘플)를 무음으로 남김 → loop 반복마다 그만큼 끊김. 곡 내용은 그 뒤에 안내문 길이만큼 온전히 있음.
- 수정: `MusicPlayer` — 재생기 2개를 번갈아 예약 재생(PlayScheduled), "무음 뒤 ~ 안내문 곡 길이" 구간만 이어 붙임. 길이가 안 맞는 곡(파일이 바뀌면)은 예전처럼 loop.
- 점검 도구: `Editor/MusicLoopCheck` (메뉴 Fantasia > Audio > Check Music Loops → `Logs/music_loop_check.txt`), 자동 플레이 `-autoplay-musicloop -musicloop-id <ID>` (게임 소리를 뽑아 반복 지점 앞뒤 무음 측정 + `musicloop_seam.wav`).
- 결과: 4곡 모두 반복 지점 ±1초 안 가장 긴 무음 0.3ms 이하 → 통과.
- 남은 것: 귀로 한 번 들어 보기 (`musicloop_seam.wav`).

## 메인 메뉴에서 소리가 안 나던 문제 고침
- 메인 메뉴 장면 카메라에 소리 받는 장치(AudioListener)가 없었음 → 메뉴 음악·클릭 소리 무음이었을 것 (짐작, 녹음하면 무음).
- `MainMenuController.Start`: 없으면 카메라에 붙임.

## 화면 크기 점검 (QA 6종) + 좁은 화면 상단 막대 고침
- 1280×720 · 1366×768 · 1920×1200 · 2560×1080 · 1280×1024 · 1024×768 모두 QA 34/0.
- 문제: 4:3·5:4에서 상단 막대가 화면 높이 10%라 두꺼워져, 조작 안내 첫 줄·Cent 숫자·의뢰 상자를 덮음.
- 수정: `BoardTopBar` — 막대 자리를 720 기준 108단위 고정(TopStrip). 16:9는 전과 같음(사진 비교).
- 확인: 1024×768에서 안내·Cent·의뢰 상자 다 보임. 상점·사건 기록·승리·전멸 화면도 잘림 없음 (글자 0.8배로 작아지는 건 원래 방식).

## UI 수정본(11/10 디자인) 게임 적용 — 팀장 지시
- 받은 파일은 `Docs/Art/UI_Revision_1110` (README에 그림과 게임 자리 짝지음).
- 게임용으로 자른 그림은 `UI/Sprites`에 새 이름으로 둠. 예전 그림은 지우지 않음.
  - HUD/Cut: `TopBar2_*`, `Timeline2_*`
  - Panels: `Panel2_Window`, `Panel2_Header`
  - Buttons: `Button2_Plain`
  - Portraits: `N18/N19 …_3x4`
- 연결은 `UIIconSetup` → UITheme. 새 칸: `WindowHeader`, `TimelineSlot`, `TimelineCurrent`.
- 창 틀 (`UGUIKit.AddWindowFrame`)
  - 떠 있는 창(Window·Box·NameBox·ResultCard·RollPanel)만 장식 틀을 창 바깥으로 두름.
  - 파티 카드·순서 칸 등 붙박이 판은 예전 테두리 그대로.
  - 아래 가운데 장식은 늘어나서 개발이 지움.
- 창 제목 칸 (`WindowTitleToHeader`)
  - 큰 창(Window, 위 끝 0.9 이하)만 "Title" 글자를 위 이름 칸으로 옮김.
  - 가운데 뾰족 끝이 글자를 가려 개발이 나무결로 덮음.
  - 상점·인벤토리는 위 공간이 없어 이름 칸 없음.
- 버튼 (`UGUIKit.ApplyButtonArt`): 모든 버튼에 사각 판. 버튼 색은 반쯤 섞고 글자는 밝게.
- 상단 바: 3조각 교체. 초상 칸 위치와 이름 글자 위치를 맞춤.
- 전투 순서 띠
  - 패키지 그림만 잘라 씀 (금 틀 = 첫 칸, 청동 틀, 바탕).
  - 아군/적 색은 칸 아래 줄로 표시.
  - 패키지 코드는 넣지 않음 (8칸 고정, Sprite 초상이라 맞지 않음).
  - 밀리는 움직임(0.42초)은 연출이라 기획 OK 후.
- 순서 칸 아래 "속도" 글자 숨김 (팀장 요청).
- 초상: "비율 조정 1" = 제임스, "2" = 점술마녀 (처음에 반대로 넣었다가 점술 창 사진으로 찾아 고침).
- 확인
  - 셀프 테스트 17
  - QA 34/0 (1920×1080 · 1024×768)
  - 1막 통플레이 클리어
  - 메뉴·설정·점술 창 사진
- 디자인 요청서 7번 추가 (`Docs/Art/Design_Request_1110`)
  - 아벨 모로 3:4 초상 필요
