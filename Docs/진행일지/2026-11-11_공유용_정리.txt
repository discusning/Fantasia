■ UI 점검 수정 (6~12번)
- 창 위 장식이 상단 바를 가리던 것 고침. 큰 창들은 제목판이 보이게 조금 내림.
- "아군 턴" 판 위로 주사위가 굴러가던 것 고침 (자동 플레이 봇 문제).
- 전투 "저지!" 글자가 순서 띠와 겹치던 것 고침.
- 칸 정보 상자 · 점술마녀 창 · 장소 정보 창: 얇은 판 + 금색 글자로 바꿈.
- 전투 위쪽 순서 칸이 띠와 겹치던 것 고침.

■ 플레이 중 찾은 문제 고침
- 보드 나무·우물·보물·분수대·점술 천막·출구 문이 90도 누워 있었음 → 바로 세움.
  (원인: 받은 모델은 원래 서 있는데, 우리 설정 코드가 일부러 눕히고 있었음)
- 전리품·피의 흔적 알림이 예전 흰 상자로 나오던 것 → 어두운 판 + 금색 글자. 긴 문장도 안 잘림.
- 지역명("런던 · 저녁")이 위 원에 가려지던 것 → 칸을 아래로 내림.
- 퇴각·탈출권: 순간 사라지던 것 → 돌아서서 뒤로 물러난 뒤 사라짐.

■ 여러 UI가 겹칠 때 순서 규칙 (팀장 결정)
- 규칙 1: 알림은 줄을 서서 하나씩. 앞 알림이 덮여 사라지지 않음.
- 규칙 2: 대화창·창 → 턴 판 → 알림 순서. 위쪽이 떠 있으면 아래쪽은 기다림.
- 규칙 3: 알림 색 구분. 경고 = 붉은색 · 의뢰 완료 = 초록 · 획득 = 금색.
- 규칙 4: 창이 뜨면 오른쪽 의뢰 칸을 흐리게.
- 기획 확인 필요: 기획서에 없던 연출이라 공유함.
