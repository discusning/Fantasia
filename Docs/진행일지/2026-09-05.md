## 3. 인벤토리 시스템 (핵심 작업)
- `BoardSession`에 고정 슬롯 배열 기반 인벤토리 추가 (`AddItem`/`RemoveItemAt`/`SwapItems`) — 전투 등 특정 소스에 종속되지 않는 범용 API (`bfbb849`)
- 전투 승리 시 `PossibleLoot`에서 무작위 아이템 지급 → 인벤토리 반영, `StatusInventoryPanel`이 `BoardSession`을 실시간으로 읽도록 변경
- 드래그 앤 드롭 상호작용 추가 (`d2cdffa`, `4603793`)
  - 슬롯 간 드래그 → 위치 교환 (빈 슬롯 포함)
  - 인벤토리 창 **전체 바깥**으로 드래그해야만 "버리시겠습니까?" 확인창 표시 — 창 안에서 슬롯을 빗나가면 원래 자리 유지
  - 더블클릭 = 사용(소비품 전용), 우클릭 = 장착/해제 토글(장비 전용)
- 아이템 획득 시 화면에 담백한 "OO 획득" 토스트 배너 표시 — `BoardSession.ItemAdded` 이벤트 기반이라 전투 외 다른 소스에서도 자동 적용, 씬 전환 중에도 유지됨 (`7c63bf4`)
- 버그 수정 (`c90a6b3`)
  - 소비품 사용 시 로그만 뜨고 실제로 사라지지 않던 문제 → 실제 제거되도록 수정
  - 장비(녹슨 검)가 더블클릭에도 "사용됨" 반응하던 문제 → 소비품 전용으로 제한
  - 우클릭이 "장착"만 되던 것을 장착/해제 토글로 변경, 상태는 `BoardSession`에 저장(씬 전환에도 유지)

## 4. 코드 정리
- `StatusInventoryPanel`과 `ItemAcquiredToast`에 중복돼 있던 코드 전용 uGUI 생성 헬퍼를 `UGUIKit` 공용 클래스로 추출, 폰트 캐싱 등 사소한 비효율도 함께 정리 (`1ba430f`)

## 검증 방법
모든 스크립트 변경은 Unity 배치 모드(`-batchmode -executeMethod ...`)로 컴파일 확인 및 임시 검증 스크립트(커밋 안 됨)로 로직 검증 후 반영. 실제 Play 모드 조작(마우스 드래그 등)은 에디터 GUI가 필요해 직접 확인은 사용자가 진행.
