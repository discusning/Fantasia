# 2026-09-14 작업 내역

## 퀘스트 완료 → NPC 대화 프로토타입
전날(2026-09-13) 만든 퀘스트 추적 UI에 이어서, "퀘스트를 완료하면 무슨 일이 일어나는가"를 프로토타입으로 확인하는 작업.

- 퀘스트 창에 "달성!" 버튼 추가 — 각 퀘스트 줄(메인/서브 공통) 제목 오른쪽 끝에 배치, 클릭하면 `BoardSession.CompleteQuest`로 해당 퀘스트를 완료 처리. 처음에는 Q 키(테스트 전용)로 임시 구현했다가, 사용자 요청으로 UI 버튼 방식으로 교체 (`e739c87` → `eff1e32`)
- 퀘스트 완료 시 대화창이 뜨는 흐름 최초 구현 — 텍스트 박스 3~4줄이 순서대로 나오고 닫히는 최소 프로토타입 (`e739c87`)
- 텍스트 박스만 화면에 떠 있고 3D 캐릭터가 안 보인다는 피드백 → 전투가 인카운터 시 별도 씬으로 전환되는 것과 같은 방식으로, 퀘스트 완료 시 전용 `DialogueTest` 씬(3D 대화 상대 placeholder + 카메라)으로 이동하도록 변경. 마지막 대사를 닫으면 자동으로 `BoardTest`로 복귀 (`b684b3a`)
- 스토리에 캐릭터가 여러 명이면 항상 같은 상대와만 대화하지 않을 거라는 피드백 → 대사마다 화자를 지정할 수 있도록 구조 변경(`DialoguePanel.DialogueLine`), 화자가 바뀌면 대화창에 이름이 갱신되고 그 캐릭터만 밝게(나머지는 어둡게) 강조되도록 `DialogueStageController` 추가 (`006de8f`)

## 검증 방법
`SceneManager.LoadScene`은 Play 모드에서만 동작하는 API라, 씬 전환 자체는 배치 모드로 자동 검증할 수 없었음 — 씬 생성/데이터 배치/화자 강조 로직은 리플렉션과 카메라 렌더 캡처로 확인하고, 실제 퀘스트 완료 → 씬 전환 → 대화 진행의 전체 흐름은 사용자가 Play 모드에서 직접 확인.
