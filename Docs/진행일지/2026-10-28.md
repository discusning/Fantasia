## 기획 UI 솔루션 Q1~Q9 반영 (팀장 확정 — Planning/UI_Solutions_Q1-Q9_2026-10-27.pdf)
- Q1 우물: 1명 골라 집중력 +1 (전원 HP·MP 30% 폐기)
- Q2 피의 흔적: 10칸 대신 숫자 + 주의·위험, 50·80 넘을 때 알림
- Q3 가운데 원 해·달(아침·낮·저녁·새벽), 현재 턴은 양옆, 월드 R은 오른쪽
- Q4 새 게임 이름 입력 (기본 "탐정"), 저장
- Q5 이긴 적·받은 보물 = 일반 칸, 쓴 우물·이벤트 = 회색 + "사용 완료"
- Q6 타임라인 다음 라운드 점선·"전투 R2 예상"·구분선, 10칸 넘으면 넘겨 보기
- Q7 적 칸 공용 표식(임시 교차 칼) + 사냥개 칸, 마우스 올리면 적 구성
- Q8 대화 창 인물 칸 (점술마녀·제임스·아벨 그림, 3직업 초상)
- Q9 조우 창 적 전체 구성
- 셀프 테스트에 우물·해달·이름·적 구성 점검 추가
- 그림 대기: 해·달 투명 PNG, 타임라인 칸 조각, 공용 적 표식 (오면 그림만 교체)
