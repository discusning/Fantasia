## 검증 방법
모든 변경은 Unity 배치 모드로 컴파일 확인 후, 실제 화면 렌더링이 필요한 부분(짤림 여부, 반투명 블렌딩, 색상, 팝업 레이아웃)은 카메라를 임시로 Screen Space - Camera로 전환해 헤드리스로 스크린샷을 찍어 직접 눈으로 확인했습니다(Overlay Canvas는 일반 카메라 렌더 캡처에 안 잡히기 때문). 순서/색상/활성화 로직처럼 화면 렌더링이 필요 없는 부분은 리플렉션으로 내부 상태를 직접 검증했습니다. 임시 검증 스크립트는 매번 사용 후 삭제하고 커밋하지 않았습니다.
