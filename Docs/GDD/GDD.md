## 2. 핵심 게임 루프 (Core Game Loop)
```
[메인 화면(영상)] → [프롤로그(VN)] → [보드 탐험(D6 이동)] → [인카운터/전투(슬롯 롤)] → [최종 보스 성 도달]
```
1. **탐험**: 1~6 주사위를 굴려 3D 보드판의 노드를 따라 이동.
2. **인카운터**: 타일별 이벤트 진행 및 몬스터 조우 시 3D 턴제 전투 씬으로 전환.
3. **최종 목표**: 타일을 전략적으로 돌파하여 맵 끝에 위치한 보스의 성에 도달 후 토벌.

### 6.2 전투

#### 무기 슬롯(게이지) & 성공 확률 구조
무기 등급이 올라갈수록 슬롯 수(잠재 화력)는 늘어나지만, 슬롯당 기본 성공 확률은 낮아진다.

| 무기 등급 | 기본 공격력 | 슬롯 구성 |
| --- | --- | --- |
| 2슬롯 | 낮음 | 50% / 50% |
| 3슬롯 | 보통 | 33% / 33% / 33% |
| 4슬롯 | 높음 | 25% / 25% / 25% / 25% |

판정 방식: 각 슬롯마다 독립 확률 검사를 수행하며, 성공한 슬롯 개수에 비례해 최종 피해량을 계산한다 (전체 성공 시 퍼펙트 타격 보너스).

#### 활력 (Focus) 시스템
- 턴 시작 시 보유한 활력을 소모해 슬롯을 100% 확정 성공으로 전환.
- 직업별로 최대 보유 활력량이 다르며, 한 턴에 여러 개 소모 가능.
- 예시 (4슬롯 무기, 활력 2개 소모): `[100% 확정] [100% 확정] [25% 확률] [25% 확률]`

#### 무기 내구도 (드랍 RNG)
무기 획득 시 3가지 내구도 등급 중 하나가 무작위로 부여되어 성능에 반영된다.

| 등급 | 반영 비율 |
| --- | --- |
| 약함 (Weak) | 33% |
| 중간 (Normal) | 66% |
| 강함 (Strong) | 100% (온전한 성능) |

### 6.3 캐릭터 / 파티

#### 5대 핵심 스탯
직업군(AD/탱커, AP)에 따라 스탯 가중치를 차등 부여한다.

| 스탯 | 설명 |
| --- | --- |
| 물리 방어력 (Physical DEF) | 물리 피해 경감 |
| 마법 방어력 (Magic DEF) | 마법 피해 경감 |
| 속도 (Speed) | 전투 턴 우선순위(Turn Order) 결정 |
| 공격력 (Physical ATK) | 물리 딜러(AD) 및 탱커의 기본 피해 계수 |
| 마력 (Magic ATK) | 마법 딜러(AP)의 마법 피해 계수 |
