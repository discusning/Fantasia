## 2. 스토리 (본편 3막)

18세기 후반 오컬트 유럽. 교단 **붉은 밤**은 영생을 위해 저승의 영혼 수확자 **잭 더 리퍼**를 강림시키려 영혼을 모으고(영혼 100개), 그 힘을 본뜬 **인공 사신**을 시험한다.

| 막 | 무대 | 목표 | 보스 |
|---|---|---|---|
| 1막 | 런던 | 연쇄 살인의 실행자·범행 방식 추적 (제임스의 의뢰) | 검시관 아벨 모로 |
| 2막 | 베르사유 | 귀족 영생 거래·교단 지부 조사 | 붉은 주교 세베린 |
| 3막 | 로마 제국 | 실종자 구출·시험체 실험 저지 | 인공 사신 · 잭의 대행자 (제1시험체) |

3막 끝: 제1시험체 처치·실종자 구출 → 더 큰 수확망과 관측자의 존재를 드러내는 **열린 결말**. 중앙 영혼 수확 코어·진짜 잭 더 리퍼는 후속 범위.

## 3. 핵심 게임 루프

```
새 게임 → 3인 편성 → 보드 탐험(주사위) → 조우(싸우기·기습·몰래 지나가기·후퇴) → 턴제 전투 → 보상·성장 → 도시(상점·숙박) → 막 보스 → 다음 지역
```

## 4. 핵심 시스템 요약 (System.md)

**자원** — HP(전투 체력) · MP(마법 직업) · 집중력(기본 3, 최대 6) · LP(부활 횟수, 최대 5). HP 0일 때 LP를 써서 부활, LP가 없으면 영구 사망, 전원 영구 사망 시 플레이 종료.

**능력치** — 힘·속도·활력·지력·행운·인지 (상한 99). 최대 HP = 활력 × 2. 레벨 1~10, 다음 레벨까지 현재 레벨 × 60 경험치.

**보드** — 파티장(1번) 1명이 파티를 이끌고 이동, 월드 턴은 [아군 턴]→[적 턴] (Decisions.md). 상단 바(임시안): 파티장·피의 흔적 G·아군/적 턴 시계+라운드·영혼 수확 S·Cent·지역명, 턴 전환 배너. 주사위 1~6, 0~눈 사이 선택 이동. 이벤트 칸 추가 이동 0/1/2(턴당 1회). 월드맵 3지역(런던 S05 → 베르사유 F18 → 로마 제국 S31, 지역마다 거점·보스·잠긴 출구 — [WorldMap.md](../Planning/WorldMap.md)), 도시 구성 [City.md](../Planning/City.md), 이벤트 칸(룬 기관차·점술마녀·십자가 석상 7기도·분수대).

**조우** — 싸우기 / 기습(인지 판정 — 성공 시 첫 라운드 아군 선공, 실패 시 적 선공) / 몰래 지나가기(속도 판정) / 후퇴(판정 없음). 보스는 몰래 지나가기·후퇴 불가.

**전투**
- 순서: 아군·적 통합 최종 속도 내림차순, 동률은 아군 우선·편성순. 속도 변화는 다음 라운드부터.
- 판정: 무기 슬롯 2/3/4개, 슬롯당 50% / 33.3% / 25% + 연관 스탯 × 0.1%p (5~95%). **전부 성공 = 크리티컬**.
- 피해: 일반 = max(0, floor(계수 × A|M) − 방어) — 슬롯 일부 실패해도 들어감. 크리티컬 = floor(2 × 계수 × A|M), 방어 무시.
- 집중력 1로 슬롯 1개 확정(행동당 1회). 일반 회피 = 5% + 속도 × 0.1%p (최대 40%). 방어 행동 = 방어 +8.
- 행동: 기본 공격 · 직업 스킬 · 소모품 · 방어 · 퇴각(2슬롯 속도 판정).

**상태 효과** — 출혈·중독·화상·혼란·공포·속박·부식·저주·죽음의 표식 등. 개인 턴 기준 기간, 같은 이름은 갱신(중독만 3스택), 턴 시작 순서: 지속 피해 → 사망 확인 → 기간 감소 → 행동.

**직업 (1차 3종)**
| 직업 | 역할 | 스킬 (패시브 / 액티브) |
|---|---|---|
| 명탐정 | 근접·수사·약점 분석 | 현장 검증 / 약점 간파 · 일점 돌파 · 장막 걷기 |
| 역병 의사 | 치료·해독·마법 지원 | 조제 숙련 / 응급 봉합 · 역병 정화 · 검은 연무 |
| 저격수 | 원거리 단일·턴 지연 | 첫 탄의 침묵 / 영점 조정 · 관통탄 · 저지 사격 |

후속 5직업: 이단심문관 · 연금술사 · 지휘자 · 암살자 · 도박가.

**적** — 소형(2슬롯) · 중형(3) · 대형(4) · 보스(4, 패턴·임계치 기믹). 1막 소형 4종: 그림자 사냥개(회피 상태·혼란·방해함) · 연성 독거미 유체(중독) · 역병 쥐(출혈·속박) · 가고일 유체(공격력 −3).

**장비·경제** — 무기 10계열, 등급 6단계(노말~스페셜), 착용 레벨, 파손·수리. 방어구·장신구 17종, 소모품 29종. 승리 보상 = Cent + 추가 슬롯 추첨, 패배 시 약탈.

**월드 압박** — 피의 흔적 G(적 턴마다 +10, 100이면 **피의 사냥**: 파티가 있는 지역에 인조 사신 4마리, 아군 턴마다 2칸 접근 — 3아군 턴 안에 1마리라도 잡으면 종료, 못 잡으면 무작위 1명 HP·MP 1) · 영혼 수확 진행도 S(100이면 진짜 사신 강림 분기 — 본편 적용은 기획 결정 대기).

## 5. 개발 범위 · 우선순위

| 차수 | 범위 |
|---|---|
| 1차 (런던 1막) | 명탐정·역병 의사·저격수, 소형 적 4종, 검시관 보스, 노말·희귀 무기, 회복·해독·집중 아이템, 상점·전리품 |
| 2차 (본편 3막) | 중·대형 적, 세베린·인공 사신, 에픽 이상 장비, 파손·수리, 영혼 수확 진행도 |
| 3차 (후속) | 추가 5직업, 중앙 코어·진짜 사신 분기, 유럽 도시 확장 |

개발 단계: M0 제작 기준 → **M1 핵심 플레이 시제품(진행 중)** → M2 런던 1막 → M3 베르사유 → M4 로마·결말 → M5 최종 점검 → M6 후속.

## 6. 아트·연출 방향

- 3D 보드 + 미니어처 느낌의 캐릭터, 전투는 낮은 대치 구도(아군 앞·적 뒤).
- 화면: 상단 행동 순서 타임라인 · 적 HP 바, 하단 3인 파티 카드(초상·HP/MP·집중력·상태·퀵 슬롯).
- UI 아트는 `Resources/UITheme`, 캐릭터·적 모델과 초상은 각 데이터의 Model/Portrait로 교체 (README 참고).
- 시작 화면 인트로 영상, 프롤로그는 VN 스타일 대화.
