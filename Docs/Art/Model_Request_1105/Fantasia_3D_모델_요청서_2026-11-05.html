항목규칙
형식FBX + 텍스처 PNG. 프로그램은 자유 (Blender 등)

재질Unity 기본(Built-in) Standard 재질로 보이게. 색 텍스처 1장이면 충분
텍스처 크기인물 1024 이하 (보스 2048) · 칸·소품 512 이하 · 건물 1024 이하. 칸 여러 종은 텍스처 1장을 같이 써도 좋음

파일 이름영문만. 위 표의 이름 사용 (예: Tile_Road_A.fbx, Tile_Road_A_Albedo.png)
전달팀 공유 폴더 판타지아_팀원공유\3D\에 넣고 알려 주기. 1개씩 와도 바로 넣어 봄
