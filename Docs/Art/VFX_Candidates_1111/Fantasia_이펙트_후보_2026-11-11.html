4. 개발 의견

  1. 추천 조합: ① + ② + ④ (모두 무료). 맞음·방어·회복·부활·보스 예고·화염병을 거의 다 덮음.
  2. ③·⑤는 부족한 것만 보충. ⑤는 만화풍이라 조심.
  3. ⑥ 유료는 1막 뒤 상태 효과가 필요할 때 다시 봄.
  4. 받는 법: 에셋 스토어 로그인 → "Add to My Assets" → Unity 패키지 관리자에서 가져오기. 개발이 받아서 넣고 화면을 찍어 다시 공유.
팀에 묻는 것
  1. 이펙트는 기획서에 없는 연출 → 기획: 1막에 넣어도 되는지, 어디부터 넣을지.
  2. 디자인: 분위기(어두운 런던)에 안 맞는 후보가 있으면 빼 주세요. 색은 개발이 바꿀 수 있음.
  3. 1막 마감(11/18)이 가까워서, 넣는다면 맞음·회복 2가지만 먼저 하는 것을 추천.
