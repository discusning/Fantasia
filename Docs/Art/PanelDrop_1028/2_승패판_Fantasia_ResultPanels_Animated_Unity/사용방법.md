# Fantasia — 승리 / 패배 패널 사슬 애니메이션

첨부한 두 PNG를 그대로 사용한 추가 버전입니다. 두 패널 모두 기존과 동일한 **낙하 → 사슬 풀림 → 반동·흔들림 → 정지**와 효과음을 적용했습니다.

## 이번 패키지에서 사용할 프리팹

| 첨부 이미지 | 용도 | 프리팹 |
|---|---|---|
| 첫 번째: 거칠고 낡은 목재 | 패배 결과 | `Assets/FantasiaPanelDrop/Prefabs/DefeatPanel.prefab` |
| 두 번째: 조각 장식이 있는 목재 | 승리 결과 | `Assets/FantasiaPanelDrop/Prefabs/VictoryPanel.prefab` |

## 빠른 적용

1. ZIP을 풀고 `Fantasia_ResultPanels_Animated.unitypackage`를 Unity에 Import합니다.
2. **Tools > Fantasia > Panel Drop > Create Victory Demo Canvas** 또는 **Create Defeat Demo Canvas**를 누릅니다.
3. **Play**를 누르면 선택한 패널의 연출과 소리가 자동 반복됩니다. 두 데모는 각각 확인하거나 이전 데모 Canvas를 끄고 확인합니다.
4. 실제 게임에는 원하는 프리팹을 기존 **Canvas 자식**으로 넣습니다. 기본값은 활성화 시 한 번 자동 재생입니다.

편집 화면에서 바로 보려면 프리팹을 선택하고 **Build / Refresh Artwork Preview**를 누릅니다. 글자와 보상 아이콘은 **Board/Content** 아래에 넣습니다.

- 원본 PNG를 새로 그리거나 색을 바꾸지 않았습니다.
- 승리 패널의 상단 조각 장식도 몸체와 함께 움직입니다.
- 낙하 시간·사슬 떨림·반동·음량은 기존과 동일하게 Inspector에서 조절합니다.
- 이전 단순 패널 프리팹도 포함됩니다. 공통 스크립트의 경로와 GUID를 유지한 업데이트이므로 별도 중복 스크립트를 만들지 않습니다.
- ZIP의 `Defeat_Preview.mp4`, `Victory_Preview.mp4`는 소리 포함 미리보기입니다. 같은 영상이 패키지의 `Preview` 폴더에도 있습니다.
- Unity Editor가 없는 환경에서 제작하여 **실제 Unity 가져오기·C# 컴파일·Play Mode 실행은 확인하지 못했습니다.** PNG 동일성·표시 영역·연결 GUID·패키지 내용과 수학 모델 미리보기를 확인했습니다.

## 공통 설정 상세 안내

# Fantasia — 패널 낙하 + 사슬 풀림 애니메이션

## 가장 빠르게 보기

1. Unity에서 **Assets > Import Package > Custom Package**를 누르고 `Fantasia_PanelDrop.unitypackage`를 가져옵니다. 모든 항목을 Import합니다.
2. 위 메뉴에서 **Tools > Fantasia > Panel Drop > Create Demo Canvas**를 누릅니다.
3. **Play**를 누릅니다. 패널 낙하와 사슬 소리가 자동으로 반복됩니다.

별도 트윈 라이브러리나 Animator 설정은 필요하지 않습니다. 이 패키지는 Unity의 **uGUI(Canvas UI)**를 사용합니다. UI Toolkit용 패키지는 아닙니다.

## 실제 게임 화면에 넣기

1. `Assets/FantasiaPanelDrop/Prefabs/HangingPanel.prefab`을 기존 **Canvas의 자식**으로 넣습니다.
2. 프리팹을 선택하고 Inspector의 **Build / Refresh Artwork Preview**를 누르면 편집 화면에서도 그림을 볼 수 있습니다. Play 시에는 자동으로 구성됩니다.
3. Rect Transform의 **Anchored Position**으로 최종 위치를, **Width**로 전체 크기를 정합니다. 기본값은 Width 1100 / Height 733.33입니다. Width 기준으로 그림 비율을 유지합니다.
4. 기본값 `Play On Enable = true`이므로 오브젝트를 켜면 한 번 재생됩니다. 기존 화면을 가리는 데모 배경은 실제 게임에는 넣지 않아도 됩니다.

직접 다시 재생하려면 Button의 On Click에 패널 오브젝트를 연결하고 **HangingPanelDrop > Play()**를 선택합니다. 이 경우 기존 버튼이 사용하는 EventSystem을 그대로 사용합니다.

```csharp
using Fantasia.UI;
using UnityEngine;

public class ResultWindowExample : MonoBehaviour
{
    public HangingPanelDrop resultPanel;

    public void OpenResult()
    {
        // Play On Enable이 켜져 있으면 SetActive(true)에서 자동 재생됩니다.
        if (!resultPanel.gameObject.activeSelf)
            resultPanel.gameObject.SetActive(true);
        else
            resultPanel.Play();
    }

    public void CloseResult()
    {
        resultPanel.gameObject.SetActive(false);
    }
}
```

## 결과 글자 / 버튼을 함께 움직이기

Inspector의 **Select Content (add TMP text here)**를 누릅니다. 선택되는 **Board/Content** 아래에 TextMeshPro 글자, 보상 아이콘, 버튼을 넣으면 패널과 함께 낙하하고 흔들립니다.

- 그림에는 글자가 들어 있지 않습니다. `승리`, `패배`, 보상 목록 등을 별도 UI로 올립니다.
- 한글은 프로젝트에서 사용하는 한글 TMP Font Asset을 지정합니다.
- 패널 그림과 사슬은 Raycast Target을 끄므로 기존 버튼 클릭을 막지 않습니다.

## 기본 연출

| 구간 | 기본 시간 | 동작 |
|---|---:|---|
| 시작 대기 | 0.12초 | 패널을 화면 위에 배치 |
| 낙하 | 0.55초 | 가속하며 떨어지고 사슬 링크가 위에서부터 드러남 |
| 멈춤 | 재생 시작 후 약 0.67초 | 짧은 정지음, 살짝 아래로 처지는 반동 |
| 안정화 | 1.05초 | 좌우 흔들림과 사슬 떨림이 줄어들며 정지 |

## Inspector 조절

| 항목 | 의미 / 기본값 |
|---|---|
| Play On Enable | 활성화할 때 자동 재생 / On |
| Use Unscaled Time | `Time.timeScale = 0`이어도 UI 애니메이션 재생 / On |
| Loop | 반복 / 프리팹 Off, 데모 On |
| Loop Delay | 안정화 후 반복까지 간격 / 2초 |
| Start Delay | 시작 전 대기 / 0.12초 |
| Fall Duration | 낙하 시간 / 0.55초 |
| Drop Distance | 낙하 거리 / 950. 화면 위로 완전히 숨기기 위한 최소 거리는 자동 확보 |
| Fall Exponent | 가속감 / 2.2. 높을수록 마지막에 빠르게 떨어짐 |
| Overshoot | 정지 시 아래로 처지는 정도 / 20 |
| Swing Angle | 최대 흔들림 각도 / 2.2도 |
| Chain Jitter | 사슬 링크 떨림 / 3.5 |
| Chain Volume / Stop Volume | 각 효과음 크기 / 0.55, 0.7 |
| On Landed | 패널이 처음 멈추는 순간 호출 |
| On Finished | 흔들림이 완전히 끝나면 호출 |

게임 코드에서 `Play()`, `ShowImmediate()`, `HideImmediate()`를 호출할 수 있습니다. 껐다 켜거나 재생 중 다시 Play해도 처음부터 재생되도록 구성했습니다.

## 적용 환경과 확인 범위

- Unity **2022.3 LTS / Unity 6의 uGUI**에서 사용하는 API를 기준으로 작성했습니다. 2D·3D 프로젝트에서 Canvas UI로 사용합니다.
- 효과음을 들으려면 씬에 활성화된 AudioListener가 하나 필요합니다. 데모 생성 메뉴는 없을 때만 하나 추가합니다.
- 원본 그림을 다시 그리지 않고, 동일 PNG의 UV 영역으로 패널과 사슬을 각각 표시합니다. 사슬은 구간을 차례로 드러내고 짧게 떨리도록 움직입니다.
- PNG 바이트 동일성, UV 영역 범위, 패키지 경로/GUID 연결, WAV 재생 길이·피크, 낙하/정착 수학과 프레임 미리보기를 확인했습니다.
- 제작 환경에 Unity Editor가 없어 **실제 Unity 가져오기·C# 컴파일·Play Mode 실행은 확인하지 못했습니다.** 미리보기 영상은 같은 좌표와 연출 계산으로 렌더링한 참고 영상입니다.
