## 개발 확인 결과 (2026-11-03)

- 만든 쪽 설명대로, **Unity에서 실제로 가져오기·실행해 본 적은 없는 자료**입니다. 개발도 아직 안 해 봤습니다.
- 스크립트는 글자 도구(TextMeshPro)가 없어도 됩니다. 설명서는 TMP 글자를 올리라고 하지만, 우리 게임은 ZEN SERIF 글꼴(UGUIKit)을 쓰므로 그쪽으로 넣습니다.
- **그대로 가져오면 게임 코드에서 못 부릅니다.** 우리 코드는 `Fantasia.Scripts` 묶음(asmdef)에 있고, 패키지는 `Assets/FantasiaPanelDrop`에 따로 풀립니다. 넣을 때 스크립트를 `Assets/_Project/Scripts/UI`로 옮기거나 묶음을 하나 더 만들어야 합니다.
- 우리 화면은 코드로 만드는데, 이 자료는 프리팹(미리 만든 화면 조각)으로 되어 있습니다. 결과 창(BattleHud)과 턴 안내 배너에 맞춰 붙이는 작업이 필요합니다.
- 사슬이 판 위로 붙어 있어 결과 창 위쪽 공간이 더 필요합니다 (디자인 요청서 10/28에도 적은 내용).

## 게임에 넣어 본 결과 (2026-11-03, 배포 빌드 · 자동 점검 `-autoplay-paneldrop`)

넣은 곳: 스크립트 `Assets/_Project/Scripts/UI/PanelDrop/`, 그림·소리·프리팹 `Assets/_Project/Resources/PanelDrop/` (파일 ID 그대로)

- **받은 그대로는 판이 안 보였음** → 고침
  - 프리팹의 판·사슬 위치 값에 Unity 형식 표시(`serializedVersion: 2`)가 빠져 값이 0으로 읽힘
  - 우리 복사본 3개 프리팹에 표시를 넣어 해결. 받은 패키지 원본은 그대로 (만든 쪽에 알려야 함)
- 고친 뒤: 승리·패배·턴 안내 모두 떨어짐 → 출렁 → 멈춤 정상, 닿을 때 소리 나옴, 판 위 글자(ZEN SERIF)도 같이 움직임
- 시간: 닿음 0.68초, 완전히 멈춤 1.73초 (설명서와 같음)
- 성능: 1080p 모든 프레임 17ms(60fps), 처음 보일 때 끊김 없음 / 4K 가끔 한 프레임 33ms
- 화질

  - 4K: 원본보다 크게 그려짐 (결과 판 1.37배, 턴 안내 1.09배) → 아주 약간 부드러움, 깨짐·계단 현상 없음
