2. 기획 확인 요청 — 설명서와 확정 기획·게임이 다른 부분

사용 설명서는 "후속 사용자 지시"를 근거로 몇 가지를 바꿨는데, 개발이 받은 확정 기획과 다르거나 게임에 없는 기능입니다. 개발이 짐작해서 정하지 않도록, 아래 질문에 답을 부탁드립니다.

Q1. 우물(초록 회복 칸)의 효과 P1 · 이미 구현된 규칙과 충돌

기획

지금 게임 (10/26 지도 칸 확정안대로): 도착하면 [이용]/[지나가기]. 살아 있는 파티원 전원 HP·MP 30% + 집중력 1 회복, 칸마다 1회.

설명서: 우물 그림으로 통일하고 살아 있는 1명을 골라 집중력 +1. "전원 HP/MP 30%는 적용하지 않는다".

질문 어느 쪽이 최신 확정인가요?
A. 지금 확정안 유지 (그림만 우물로) · B. 설명서대로 변경 (1명 선택 + 집중력 1)
개발: A면 그림만 교체. B면 선택 창 변경 약 0.3일.

Q2. 상단의 피의 흔적 10칸 삭제 P1

기획

지금 게임: 상단 왼쪽 빨간 10칸 = 피의 흔적. 다 차면 "사신이 가까워진다" → 피의 사냥(사신이 쫓아옴)이 시작됨. 플레이어가 위험을 미리 아는 유일한 표시.

설명서: 상단 10칸 삭제. 피의 흔적 아이콘(Z01)은 경고창·도움말에서만.

질문 지우면 플레이어가 피의 흔적을 어디서 보나요?
A. 상단 유지 · B. 10칸 대신 작은 아이콘 + 숫자(예: 🩸 70/100)로 상단에 · C. 상단에서 빼고 경고(50·80·100 넘을 때 알림)만
개발 추천: B (공간은 줄이고 위험은 계속 보임).

Q3. 상단 가운데 원 = 해/달 (낮·밤) P1 · 새 기능 여부

기획

지금 게임: 가운데 원(위 사진)은 "아군 턴 / 적 턴 + 라운드 숫자". 게임에 낮·밤 개념이 없음.

설명서: 가운데 원에 해(아침·낮)/달(저녁·새벽). 턴 시계 조각은 보관. "낮밤 전환 주기는 이번 자료에서 정하지 않는다".

질문 ① 낮·밤을 새 시스템으로 넣나요? 넣는다면 바뀌는 주기(몇 라운드마다)와 효과(밤에 적이 강해지는 등)가 있나요? 효과 없이 그림만 바뀌나요?
② 지금 가운데에 있는 "아군 턴/적 턴"과 "라운드" 표시는 어디로 옮기나요? (지금 누구 차례인지는 플레이에 꼭 필요함)
개발: 그림만 바꾸는 낮·밤이면 0.5일, 효과가 있으면 규칙 기획서 필요.

Q4. 파티장 초상 옆 "플레이어 이름" P2 · 새 기능

기획

지금 게임: 이름 입력이 없음. 그 자리에 파티장 직업명("명탐정")과 "파티장"이 표시됨.

설명서: 파티장 초상 오른쪽에 플레이어 이름. 이름과 직업명은 구분.

질문 A. 새 게임 때 이름 입력 창을 새로 만든다 (기본값 예: "탐정") · B. 이름 대신 지금처럼 파티장 직업명
개발: A는 입력 창 + 저장 연결 약 0.5일.

Q5. 이긴 적 칸·받은 보물 칸을 "일반 칸"으로 P2

기획

지금 게임: 처치한 적 칸·사용한 칸은 어두운 색으로 남아 "이미 끝난 곳"을 구분.

설명서: 승리한 적 칸·받은 보물 칸은 일반 칸과 똑같이. 퇴각·몰래 지나간 칸은 적 표식 유지(지금과 같음).

질문 일반 칸과 똑같이 보이게 할까요? (회복 칸·이벤트 칸을 쓴 뒤는 어떻게?)
개발: 표시만 바꾸면 되어 0.1일.

Q6. 행동 순서(타임라인) 칸 수 — 틀 8칸 vs 지금 최대 10칸 P1 · 디자인 함께

기획 · 디자인

지금 게임: 이번 라운드 + 다음 라운드(흐리게, "R3 예상")를 이어서 최대 10칸. 초상 아래 속도 숫자, ↑↓ 화살표 (10/26 속도 확정안).

받은 틀(N04): 가운데 초상 칸 8개가 그림에 붙어 있음. 설명서: "그림을 늘리지 말고 칸 부분을 반복".

요청 디자인: 칸 1개짜리 조각과 좌우 끝 장식을 따로 주면 개발이 인원수만큼 이어 붙입니다. "다음 라운드 예상" 칸 모양(흐리게? 다른 테두리?)도 정해 주세요.

Q7. 지도 적 표식 — 사냥개만 있음 P1 · 디자인 함께

기획 · 디자인

지금 게임: 런던 적 칸 10곳 = 역병 쥐·연성 독거미·가고일·그림자 사냥개 조합(10/26 확정). 받은 지도 표식은 사냥개(Z24) 1종. 설명서도 "쥐·거미·가고일 칸까지 사냥개 얼굴로 통일하지 않는다".

질문 A. 적 칸 공용 표식 1개 + 사냥개 칸만 사냥개 · B. 종류별 표식(쥐·거미·가고일) 3개 추가 · C. 칸에는 공용 표식, 마우스를 올리면 적 구성 글자
개발 추천: A + C (그림 1장 추가로 해결, 구성은 글자로 정확히).

Q8. 대화 창에 인물 그림 칸 넣기 (기존 대기 항목) P1

기획

지금 게임: 대화 창에 이름·대사만 있음. 이번에 점술마녀·제임스·아벨 모로 인물 그림(N18~N20)을 받음.

질문 대화 창 왼쪽에 인물 그림 칸을 넣어도 될까요? (화면 구성 변경이라 OK가 필요) · 명탐정·역병 의사·저격수의 대화 그림도 필요한가요?
개발: OK면 0.5일. 받은 JPG는 직사각형이라 액자 안에 그대로 써도 됨.

Q9. 조우 창에 적 구성 전체 표시 (기존 대기 항목) P2

기획

지금 게임: 조우 창에 칸의 대표 적 1마리만 보이고, 전투에 들어가면 조합 전체(예: 쥐 2 + 가고일 1)가 나옴.

질문 조우 창에 "역병 쥐 ×2 · 가고일 유체 ×1"처럼 전체 구성을 보여줄까요?
