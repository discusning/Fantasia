1. 상단 배너 (N07) — 통째로 늘리면 원이 찌그러짐

  • 배너가 나무판 · 원 · 지역명 칸이 한 장으로 붙어 있어, 화면 폭(16:9 · 21:9 등)에 맞춰 늘리면 원이 납작해짐
  • 개발이 3조각으로 잘라 붙여서 지금은 해결됨 (②가 실제 게임)
부탁 다음에 늘어나는 그림을 줄 때는 조각으로 나눠 주세요 — 늘어나도 되는 부분(나무판 가운데)과 고정 장식(원 · 모서리)을 따로.

2. 그림 주변 투명 여백이 큼 (전체)

  • 예: 영혼 게이지 틀은 2048×683 중 실제 그림이 빨간 칸뿐 (높이의 약 1/4)
  • 개발이 픽셀을 재서 잘라내야 하고, 빈 공간도 메모리를 씀
부탁 그림 크기에 딱 맞춰(여백 없이) 저장해 주세요.

3. 영혼 게이지 틀 (N05) — 안쪽이 불투명

  • 틀 안쪽 판이 불투명해서, 틀을 위에 그리면 채움(N06)이 안 보임
  • 개발이 채움을 틀 위로 올려서 지금은 해결됨 (채움 그림에 칸 나눔이 있어 괜찮음)
부탁 게이지처럼 안이 채워지는 틀은 채워질 자리를 투명하게 해 주세요.

4. 메뉴 창 바깥 틀 (N08) — 가운데 장식 늘어남 · 작은 창

  • 게임 창은 비율이 제각각 (상점 약 2:1 · Esc 메뉴 약 1:1 · 확인창 약 3.5:1)
  • 위·아래 가운데 꽃 장식이 창 폭에 따라 늘어남 (빨간 원)
  • 모서리 장식이 두꺼워 확인창처럼 작은 창은 글자 들어갈 안쪽이 크게 줄어듦
  • 위 장식이 창 밖으로 튀어나와, 화면 위쪽에 붙은 창은 잘릴 수 있음
부탁 (P1) ① 위·아래 가운데 장식을 따로 떼어 주세요 (가운데에 그대로 붙임) · ② 작은 창용으로 모서리 장식이 얇은 버전 1개.

5. 버튼 4상태 (N14~N17) — 글자 자리 좁음 · 작은 버튼

  • 양 끝이 뾰족하고 위아래 가운데 장식이 있어 글자 자리가 좁음 → "몰래 지나가기"(6글자)가 겨우 들어감
  • 정사각형 버튼(× 닫기 · ◀ ▶)에는 쓸 수 없음 (빨간 칸)
  • 버튼이 작아지면(원본 2048px → 화면 약 100~170px) 장식이 뭉개짐
  • 게임 버튼은 크기·비율이 제각각 (오른쪽 아래: 지금 전투 행동 버튼 7개)
부탁 (P1) ① 가운데 장식 따로 · ② 글자 자리(가운데 판)를 지금보다 넓게 · ③ 정사각형·작은 버튼용 단순한 모양 1개 (기본·강조·비활성·눌림 4상태).

6. 승리·패배 표지판 (N11·N12) — 보상 글자

  • 나무판 줄무늬가 강해서 보상 목록(작은 글자 4줄)이 잘 안 읽힘
  • 위 쇠사슬 때문에 결과 창 위쪽 공간이 더 필요함 (개발이 배치 조정)
  • 패배 표지판은 가장자리가 부서진 모양이라 창 틀과 모양이 다름
부탁 글자 들어갈 자리의 무늬를 약하게 한 버전 — 어려우면 표지판은 "승리 / 패배" 제목에만 쓰고 보상 목록은 메뉴 창 안에 두겠음.

7. 전투 행동 순서 틀 (N04)

  • 받은 틀: 같은 크기 8칸이 붙은 한 장
  • 지금 게임: 최대 10칸 · 첫 칸(지금 차례)이 더 큼 · 칸 아래 "속도 73"·"전투 R2 예상" 글자, 다음 라운드 칸은 점선
  • 개발이 칸 1개와 양 끝을 잘라 쓸 수 있음
부탁 (P2) 칸 1개 · 왼쪽 끝 · 오른쪽 끝 3조각 (+ 가능하면 큰 첫 칸 1개). 칸 아래 글자 자리는 비워 두기.

8. 대화 인물 (N18~N20) — 얼굴이 작음

  • 대화 창 인물 칸(1080p 기준 약 190×210)에 전신을 넣으면 얼굴이 작아 표정이 잘 안 보임
  • 개발이 얼굴 위주로 잘라 쓸 수 있음 (가운데 예시)
  • 아벨 모로는 "상처 완화 대체본"으로 교체함
부탁 (P2) 대화용 얼굴·상반신 위주 버전 (세로 3:4 정도). 없으면 개발이 잘라 씀.

9. 나무 바탕 위 작은 글자 (공통)

  • 상단 바의 작은 글자(명탐정 · 파티장, 6/100)가 나무 무늬 때문에 흐림 — 그림자를 넣었지만 한계가 있음
부탁 글자가 올라갈 자리(이름·숫자 줄)는 무늬를 약하게 한 버전이 있으면 좋음.

정리 — 다음 그림을 줄 때 지켜 주면 좋은 것

  • 늘어나는 그림(창·버튼·배너·틀)은 조각으로 — 늘어나는 부분과 고정 장식을 따로
  • 투명 여백 없이 그림 크기에 딱 맞춰 저장
  • 게이지처럼 채워지는 틀은 채워질 자리 투명
  • 글자 들어갈 자리는 무늬 약하게
  • 작은 버튼(정사각형)용 단순한 모양 1개
