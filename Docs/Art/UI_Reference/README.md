# UI 그림 자료 받은 것 정리 (2026-10-27)

받은 자료 3가지와 둔 곳, 그리고 **지금 게임·확정 기획과 대조한 결과**입니다.
설명서 원본: [`Docs/Art/Fantasia_Icon_Usage_Guide.pdf`](../Fantasia_Icon_Usage_Guide.pdf) (30쪽, 2026-10-26)

## 받은 자료와 둔 곳

| 자료 | 개수 | 형식 | 둔 곳 | 게임에 바로 쓸 수 있나 |
|---|---|---|---|---|
| 아이콘 Z01~Z44 | 44장 | PNG, 배경 투명, 512×512 (게이지 2장은 1024×128) | `Assets/_Project/UI/Sprites/Icons/` | **예** — UI 그림으로 가져오기 설정 완료 |
| 노션 이미지 N01~N20 | 20장 | JPG, 배경 없음(짙은 회색으로 채워짐) | `Docs/Art/UI_Reference/Notion_N01-N20/` | **아니오** — 확인·공유용 (설명서도 "게임 UI의 투명 PNG를 대신하지 않는다"고 적음) |
| 아이콘·UI 사용 설명서 | 30쪽 | PDF | `Docs/Art/` | 문서 |

- 설명서에는 "같은 아이콘의 128/256/512 크기 3종"이라고 되어 있지만, 받은 폴더에는 **512 크기 1종씩**만 있음 (게임에서는 512 하나로 충분 — 작게 줄여 씀)

## 2. 쓰려면 투명 PNG 원본이 필요한 것 (N01~N20)

상단 배너(N07), 해·달(N01·N02), 타임라인 틀(N04), 영혼 게이지(N05·N06), 메뉴 창(N08·N09), 버튼 4상태(N14~N17), 승리·패배 표지판(N11·N12)은 **JPG라 배경이 짙은 회색으로 채워져 있음** → 게임 화면에 올리면 네모난 회색 바탕이 그대로 보임.
→ **아트팀에 투명 PNG 원본 요청 필요**

- 대화 인물 N18~N20(점술마녀·제임스·아벨 모로)은 직사각형 초상이라 JPG로도 액자 안에 넣을 수 있음. 다만 대화 창에 초상 칸을 넣는 것은 화면 변경이라 기획 OK가 먼저 필요함 (기존 대기 항목)

## 3. ⚠ 지금 확정 기획·게임과 다른 부분 (기획 확인 필요)

설명서가 "후속 사용자 지시"를 근거로 바꾼 내용인데, 개발이 받은 확정 기획과 다르거나 게임에 없는 것들입니다. **누구의 지시인지, 기획 확정인지 확인 부탁**.

| # | 설명서 내용 | 지금 확정 기획·게임 | 확인할 것 |
|---|---|---|---|
| 1 | **우물(회복 칸)**: 생존 캐릭터 **1명 골라 집중력 +1** | 지도 칸 확정안(10/26): **전원 HP·MP 30% + 집중력 1** (구현 완료) | 어느 쪽이 최신 확정인지 |
| 2 | 상단 배너에서 **피의 흔적 10칸 삭제** | 피의 흔적(G)이 차면 피의 사냥이 시작됨 — 지금은 상단에서만 보임 | 지우면 플레이어가 G를 어디서 보는지 (설명서는 경고창·도움말에만 Z01) |
| 3 | 상단 가운데 원 = **해/달 (낮·밤)**, 턴 시계는 보관 | 게임에 **낮·밤 개념이 없음**. 지금 가운데 원은 "아군 턴/적 턴 + 라운드" | 낮·밤 시스템을 새로 넣는지, 바뀌는 주기는? / 아군·적 턴과 라운드 표시는 어디로? |
| 4 | 파티장 초상 오른쪽에 **플레이어 이름** | 게임에 플레이어 이름 입력이 없음 (지금은 파티장 직업명) | 이름 입력을 새로 만드는지 |
| 5 | **이긴 적 칸·받은 보물 칸은 일반 칸**으로 | 지금은 처치한 칸·사용한 칸이 **다른 색(회색 계열)**으로 남음 | 일반 칸과 똑같이 보이게 할지 (단순 표시 변경) |
| 6 | 타임라인 틀(N04)은 **8칸** | 지금 타임라인은 최대 **10칸** (이번 라운드 + 다음 라운드 예상) | 틀을 늘리는 방법 (설명서: 칸 부분 반복) |
| 7 | 지도 적 표식은 Z24 사냥개만 있음 | 런던 적 칸은 쥐·거미·가고일·사냥개 조합 | 쥐·거미·가고일 표식 추가 제작 / 그 전까지 공용 적 표식? |

## 4. 아직 없는 그림 (설명서 29쪽도 "추가 제작 필요"로 적음)

- 파티 카드 최종 틀, 캐릭터·적 초상, 쥐·거미·가고일 지도 표식, 베르사유·로마 거점 그림, 파티장 표식, 점술마녀 카드 앞면 3종, 전투 행동 버튼 아이콘(공격·스킬·소모품·방어·부활·퇴각)

## 제안하는 순서

1. **기획 확인** — 3번 표의 1~5 (특히 1번 우물은 이미 구현된 규칙과 충돌)
2. **바로 적용** — 1번 표의 투명 아이콘 (규칙 변화 없음, 그림만 교체)
3. **아트 요청** — N 이미지 투명 PNG 원본 + 4번 목록
4. 원본이 오면 배너·메뉴 창·버튼·표지판 교체

## 적용 현황 (2026-10-27)
- 1번 표의 아이콘 적용 완료 (타임라인 아군·적 행동 Z18·Z19는 타임라인 틀(Q6)이 오면 함께)
- 연결: Unity 메뉴 **Fantasia > UI > Apply Icon Set** — 아이콘을 같은 파일 이름으로 바꿔 넣으면 다시 실행하지 않아도 바뀜
