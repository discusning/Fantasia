# 판타지아 에셋·UI 요청 목록 (2026-10-24)

> 아트·사운드 담당용. 지금 게임은 전부 **임시 도형·단색**으로 돌아가고, 아래 칸에 파일을 넣으면 **코드 수정 없이** 바뀌게 만들어 둠.
> 우선순위: **P1** = 1차(1막 런던) 완성에 필요 · **P2** = 있으면 좋음 · **P3** = 2차 이후(베르사유·로마, 나머지 직업).
> 마감 11/18 — P1은 **11/7까지** 받아야 교체·확인 시간이 있음.

## 0. 공통 규격

| 항목 | 규격 |
|---|---|
| 2D 그림 | PNG(투명 배경), sRGB. UI는 기준 해상도 1280×720에서 보이는 크기의 **2배**로 그리기 |
| 늘어나는 틀(패널·버튼·게이지) | 9-slice 가능하게: 모서리 장식은 네 귀퉁이에만, 가운데는 단순 반복 (테두리 폭 알려주기) |
| 색이 바뀌는 칸 | HP 바·아군/적 테두리 등은 **흰색~회색으로** 그려 주면 코드가 색을 입힘 (따로 표시) |
| 3D 모델 | FBX, 1 unit = 1m, 정면이 +Z, 발 기준점(pivot)이 바닥 가운데. 재질은 Built-in Standard(URP 아님) |
| 3D 크기 | 사람 키 약 2m, 소형 적 0.8~1.4m, 보스 3~3.6m |
| 폴리곤 | 캐릭터·적 5천~1만 삼각형 이하, 보드 칸·소품 1천 이하 (보드에 720칸이 한꺼번에 나옴) |
| 파일 이름 | 영문·숫자·밑줄 (예: `icon_skill_pinpoint_breach.png`) — 아래 표의 "이름 예" 따라가기 |
| 넣는 곳 | `Assets/_Project/Art/` 아래 (Models / Textures / UI / Icons / VFX), 사운드는 `Assets/_Project/Audio/` |
