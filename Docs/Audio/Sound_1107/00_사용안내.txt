판타지아 1막 런던 - MP3 사운드 22종
제작일: 2026-11-07

1. 구성
배경음악 4곡 + UI 5개 + 지도 3개 + 전투 8개 + 결과 2개 = 총 22개.
모든 오디오: MP3 / 48,000 Hz / 192 kbps / 스테레오.
한글 용도와 개발용 ID를 모두 파일명에 표기했다.
예: 05_버튼클릭_작은딸깍__UI_Click.mp3
파일 탐색기에서 용도를 확인하고, 개발에서는 ID를 기준으로 연결하면 된다.

2. 제작 방향
1774년 런던의 역병·교단·검시소를 떠올리는 어둡고 무거운 고딕 분위기.
배경음악과 결과 곡은 이 프로젝트를 위해 새로 작곡했다.
현악, 첼로, 하프시코드, 교회 오르간, 종, 팀파니 계열 악기로 렌더링했다.
일반 전투는 빠른 4박자, 보스전은 무거운 6/8 리듬으로 구분했다.
나머지 효과음은 파형·필터 노이즈·재질 공명·잔향을 조합해 새로 합성했다.
현장 녹음이나 외부 완성곡·외부 완성 효과음을 내려받아 재포장한 음원은 아니다.
이번 파일들은 직접 작곡·합성한 버전이며, AI 음원 생성 서비스에서 만든 결과물은 아니다.

3. BGM 반복 재생
4곡 모두 정확한 마디 길이에 맞추고 반복 구간의 잔향이 이어지도록 렌더링했다.
긴 시작 무음과 곡 끝의 일반적인 페이드아웃을 넣지 않았다.
MP3의 인코더 지연·패딩을 처리하는 Xing/LAME 정보를 포함했다.
검증에서는 이 정보를 반영해 디코딩한 길이가 목표 길이와 일치했다.
다만 실제 엔진·재생기가 이 정보를 무시하면 MP3 반복 지점에 틈이 생길 수 있다.
게임에 적용할 때 2회 이상 반복해 연결 상태를 확인해야 한다.
지원되는 경우, MP3를 한 번 PCM으로 디코딩한 버퍼 전체를 반복하면 된다.

4. 게임에서 제어할 부분
보스 처치 시 BGM_Boss_Abel의 0.7초 페이드아웃은 게임 재생 코드에서 실행한다.
이 파일 끝에 0.7초 페이드아웃을 넣으면 반복 재생 때마다 음량이 줄어들기 때문에 넣지 않았다.
전투 승리·보스 처치·1막 클리어에는 Result_Victory를 사용한다.
전투 패배·조사대 전멸에는 Result_Defeat를 사용한다.
결과 곡은 별도 반복 재생 없이 한 번만 재생한다.
기존 Chain_Rattle, Panel_Stop과의 동시 재생 음량은 게임 안에서 최종 조정한다.
요청서에 이미 보유한 것으로 적힌 위 두 사슬·정지 파일은 제작 수량에 포함하지 않았다.
선택 항목인 장비 장착·시설·방어·상태이상·경고는 필수 22종의 범위 밖이다.

5. 개발용 파일명이 필요할 때
Windows: 동봉한 '개발용_ID파일_만들기.bat'를 실행한다.
macOS/Linux 또는 Python 사용 환경: '개발용_ID파일_만들기.py'를 실행한다.
둘 다 한글 파일을 그대로 두고, '개발용_원본ID' 폴더에 ID.mp3 이름으로 복사한다.
예: UI_Click.mp3, BGM_Battle.mp3.
그 폴더의 22개 MP3를 요청서의 게임 사운드 경로에 옮기면 된다.
게임이 원래 지원하는 .mp3 확장자로 연결되어 있는지도 개발에서 확인한다.

7. 검사 범위
22개 모두 MP3 디코딩 성공, 48kHz·스테레오 확인.
디코딩 후 길이 일치, 5ms 이상의 시작 무음 없음, 디지털 최대치 초과 없음 확인.
자주 재생하는 클릭·이동·판정음은 다른 효과음보다 낮은 기준 음량으로 조정했다.
배경음악끼리, 효과음끼리 음량 수준을 맞췄다. 최종 밸런스는 게임에서 조정한다.
실제 게임에서의 음량·중첩·동시 발음·사슬 효과음과의 조합 검수는 별도로 필요하다.
