1. 파일 규칙

항목규칙
형식.wav 또는 .ogg (mp3도 되지만 반복 이음새가 튈 수 있음). 44.1kHz 또는 48kHz
파일 이름아래 표의 ID 그대로. 예: Battle_Hit.wav, BGM_Battle.ogg
음악스테레오. 반복 재생되므로 끝과 처음이 자연스럽게 이어지게 (1~3분이면 충분)
효과음모노 또는 스테레오. 앞의 빈 소리(무음)는 잘라 주세요 — 누르는 순간 바로 나야 합니다
음량파일끼리 대략 비슷한 크기로. 세밀한 크기는 개발이 게임 안에서 맞춤
전달팀 공유 폴더 판타지아_팀원공유\사운드\에 넣고 알려 주기
출처·허락받아 온 소리는 어디서 받았는지(사이트·제작자·주소)와 사용 허락 종류를 같이 적어 주세요. 출처를 모르는 소리는 넣을 수 없습니다. (아래 7장 표에 적으면 됨)

2. 분위기

  • 배경: 1774년 런던, 역병·교단·검시소 — 어둡고 무거운 고딕 분위기
  • 악기 느낌(짐작): 현악·오르간·하프시코드·종소리·낮은 북. 전자음·밝은 팝은 피하기
  • 화면 느낌: 먹색 돌, 낡은 천, 녹슨 황동, 마른 피 (기획 미술 기준)
  • 판(게시판)이 사슬에 매달려 떨어지는 연출이 있음 — 사슬 소리는 이미 있음 (3장 끝)

3. 음악 — 4곡 (반복 재생)

파일 이름 (ID)언제 나오나어떤 느낌 (짐작)순위
BGM_Field_London런던 지도(보드) 위에 있는 동안가장 오래 듣는 곡. 긴장되지만 시끄럽지 않게, 탐색하는 느낌1
BGM_Battle일반 전투빠르고 긴장감. 짧은 전투가 많으니 앞부분부터 바로 분위기가 나게1
BGM_Boss_Abel보스 "검시관 아벨 모로" 전투일반 전투보다 무겁고 불길하게. 검시소·해부·수은 느낌. 보스를 잡으면 0.7초 동안 작아지며 멈춤1
BGM_Menu메인 메뉴·파티 구성·이름 입력조용하고 쓸쓸한 도입부 느낌2

승리·패배·게임 오버는 음악이 아니라 짧은 효과음(Result_Victory, Result_Defeat)으로 처리합니다 → 4장.

4. 효과음 — 18개

길이는 권장값(짐작)입니다. "자주"라고 적힌 소리는 계속 들리므로 짧고 귀에 거슬리지 않게 부탁합니다.
