## 단계 1 — D10 슬롯·집중력·피해·회피 계산 (다음 착수 1순위)

**왜 먼저:** 순수 로직이라 기획 추가 자료 없이 System.md만으로 끝낼 수 있고, D09·D11·D13·D14가 전부 이걸 쓴다.

### 1-1. 선행 스키마 보강 (D03 연장)
- [ ] `WeaponDefinition`: 착용 보정을 문자열(`WearStatBonusDescription`)에서 **구조화된 `StatBlock WearStatBonus` + `int MaxMPBonus`** 로. 슬롯 확률이 "힘/인지/지력 + 착용 보정"을 참조하므로 필수.
- [ ] `WeaponCategory` 확장 메서드에 **참조 스탯**(단검·검·대검=힘 / 창·활·권총·화승총=인지 / 스태프·마법서·악기=지력), **관통률**(창 25%, 화승총 50%) 추가.
- [ ] `EnemyDefinition.SlotSuccessRate`는 적이 **고정 확률을 직접 사용**(System.md "적은 자신의 슬롯별 확률을 직접 사용") → SlotCheck에 "고정 확률" 오버로드 필요.

### 1-2. 구현 (새 파일 `Scripts/Combat/DamageCalculator.cs` 등, 순수 static)
| 규칙 | System.md 근거 |
|---|---|
| 슬롯 p = clamp(기본 + 스탯×0.1%p + 보정, 5~95%), 슬롯 독립 | 공격·조우·회피 확률표 |
| 집중력 확정은 **행동당 1개**, 스킬 집중 비용과 별개, 부족하면 선택 불가 | 레벨·기본 자원 |
| 행운 판정·전리품 추첨엔 집중력 불가 | 레벨·기본 자원 |
| 일반 피해 = max(0, floor(계수 × A|M) − 대응 방어) | 공통 정의 |
| 크리티컬(전 슬롯 성공) = floor(2 × 계수 × A|M), 방어 무시 | 공통 정의 |
| 관통 50%: 일반 피해에서 방어 절반만 적용, 크리티컬엔 재적용 X | 공통 정의 |
| 일부 슬롯 실패해도 일반 공격은 기본 피해 (빗나가지 않음) | 공통 정의 |
| 일반 회피 = 5% + 속도×0.1%p + 보정, **최대 40%** — 아군 회피는 적 크리티컬에도 적용 | 확률표 |
| 회피 상태 적: 비크리티컬 회피, 크리티컬은 명중 | 확률표 |
| 처리 순서: 회피 → 크리/일반 피해 → 방어/감소 → HP 차감 → 상태 효과 → 파손 | 상태 효과 처리 순서 |
| 방어 행동: 다음 개인 턴까지 물/마방 +8 | 확률표 하단 |
| 맨손: 2슬롯·힘·무기 보너스 0 | 공통 정의 |
| 초과 피해는 회복·흡수 계산에서 제외 | 공통 정의 |

- [ ] UI용 표시 데이터: **슬롯별 확률**과 **전체 크리티컬 확률**(p^n, 집중 1개 시 p^(n−1)) 둘 다 반환.

### 1-3. 검증 (`Editor/DamageSelfTest.cs`, 기존 셀프테스트 패턴)
System.md 표 값을 그대로 기대값으로:
- 스탯 71: 2슬롯 p=57.1% → 전체 32.60% / 집중1 57.10%
- 3슬롯 p=40.433% → 6.61% / 16.35%,  4슬롯 p=32.1% → 1.06% / 3.31%
- 공격력 21, 계수 1.0, 크리티컬 → 42 (방어 무관)
- 일반 피해 하한 0, 관통 50% 일반만 적용, 크리티컬 시 관통 무시
- 회피 상한 40%, 확률 5/95% 클램프
- 몬테카를로(예: 10만 회)로 확률 근사 ±0.5%p 확인

8. **무기 최대 MP 보정(스태프 +8 등)** — 직업 초기 MP 표(역병 의사 132)가 시작 무기 보정 포함인가? 지금은 `WeaponDefinition.MaxMPBonus`에 값만 저장하고 최대 MP엔 미반영.
9. **관통 후 남은 방어력 반올림** — 방어 5, 관통 50% → 2(내림)로 가정 중 (`AttackResolver.NormalDamage`).
